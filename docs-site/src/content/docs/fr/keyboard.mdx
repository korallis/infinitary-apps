Tout dans Infinitary fonctionne au clavier.
Tab passe d’une commande à l’autre, et les flèches se déplacent dans une liste.

## Recherche de commandes {#command-search}

Appuyez sur <kbd>⌘K</kbd> sur un Mac, ou sur <kbd>Ctrl+K</kbd> sous Linux et Windows, pour ouvrir la recherche de commandes.
Tapez quelques mots, choisissez une commande avec les flèches et appuyez sur Enter.
Toutes les commandes de cette page s’y trouvent, avec leur touche à côté, y compris celles qui n’en ont pas.

## Préréglages {#presets}

Infinitary propose des ensembles de touches appelés préréglages : Vim, Emacs, VS Code, Tmux, Legacy.
Une nouvelle installation commence avec Vim.
Legacy n’est proposé que si vous utilisiez Infinitary avant l’arrivée des préréglages.
Choisissez un préréglage dans **Réglages**, sous **Clavier**.

## Changer une touche {#change-a-key}

Dans **Réglages**, sous **Clavier**, chaque commande propose **Capturer**, **Retirer** et **Réinitialiser**.
Appuyez sur **Capturer**, puis sur les touches voulues, puis sur Enter pour les enregistrer.
Si une autre commande utilise déjà ces touches, Infinitary vous dit laquelle avant que rien ne change.

## Toutes les commandes et leurs touches {#every-command-and-its-keys}

Un tiret signifie que la commande n’a pas encore de touche : exécutez-la depuis la recherche de commandes, ou attribuez-lui la touche de votre choix.
Deux touches séparées par une espace se pressent l’une après l’autre.
