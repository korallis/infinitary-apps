Download the stable release of Infinitary for [Mac](https://getinfinitary.com/downloads/#macos), [Linux](https://getinfinitary.com/downloads/#linux) or [Windows](https://getinfinitary.com/downloads/#windows).
If you want to verify a download, compare its SHA-256 checksum with the one shown beside that file on the downloads page.

## On a Mac

Download the **Disk image (.dmg)** for either an Apple silicon or Intel Mac.
Open it and drag Infinitary to **Applications**.
If you choose the **ZIP** instead, open it and move the extracted Infinitary app to **Applications**.

## On Linux

Choose the **.deb** package for Ubuntu or Debian, or the **.rpm** package for Fedora, and open it with your system’s software installer.
For Arch or Omarchy, use the Arch package recipe; for NixOS, use the Nix recipe.
On other x64 Linux systems, download the **AppImage**, allow it to run as a program in its file properties, then open it.

## On Windows

Infinitary for Windows is experimental.
Download the **installer (.exe)** for a Windows 11 PC with an Intel or AMD 64-bit processor.
The installer is not yet signed with a certificate Microsoft verifies, so Windows does not know its publisher and warns twice before installing:

1. If your browser says the file is not commonly downloaded, choose **Keep**, then **Keep anyway**.
2. When you open it, Windows says “Windows protected your PC” with an unknown publisher.
   Choose **More info**, then **Run anyway**.

If Smart App Control is on, Windows blocks this build and offers no way to run it.
Please keep Smart App Control on and wait for the signed build.

The installer installs Infinitary for you alone, adds it to the Start menu and opens it.
If your PC has no Git for Windows, Infinitary offers to install it at its first launch, since your crew needs it.

## On iPhone and iPad

Infinitary for iPhone and iPad is in private TestFlight.
[Email help@getinfinitary.com to request an invitation](mailto:help@getinfinitary.com?subject=Infinitary%20TestFlight%20request).
See [iPhone and iPad](/iphone-and-ipad/) for how to join your computer.

## What you need

- **A computer.**
  A Mac with macOS 12 or later, a Linux computer with an x64 processor, or a Windows 11 PC with an x64 processor (experimental).
- **An AI subscription.**
  Your first mate needs at least one subscription that can answer: Codex, Grok, Claude, Kimi Code, Copilot, OpenRouter with an API key, or Amazon Bedrock with your AWS sign-in.
- **Claude Code, for Claude.**
  If you use a Claude subscription, install Claude Code on that computer first.
  Infinitary uses the Claude Code you installed.

## Your first launch

1. Open Infinitary.
   The window welcomes you and shows a button for each provider.
2. Pick your provider and sign in the way it asks: in your browser, with a code, or with a key you paste.
3. When a subscription can answer, the message box opens and your first mate is ready.

Set up your first mate on a computer that stays on as much as possible.
Your other devices need your first mate awake.

To update or remove Infinitary later, see [Update and remove Infinitary](/update-and-remove/).
If something does not work, see [Get help](/get-help/).
