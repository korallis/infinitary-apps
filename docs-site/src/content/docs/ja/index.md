Infinitary は、自分専用の AI スタジオです。
macOS、Linux、Windows 用のデスクトップアプリです。
話す相手は一人の一等航海士だけで、作業は AI の乗組員たちが行います。

## タスクの流れ {#how-a-task-goes}

1. メッセージ欄で、してほしいことを一等航海士に伝えます。
2. 一等航海士が依頼をタスクに分け、それぞれのタスクを乗組員に任せます。
3. 乗組員はそれぞれプロジェクトの専用の作業コピーで作業するので、元のファイルはそのまま残ります。
4. 乗組員は、あなたの判断が必要なときや作業を終えたときに、カードを持ってきます。
5. カードで判断を下すと、乗組員たちが作業を続けます。

判断が必要なことは、カードとして届きます。
乗組員は知っておくべきことだけを持ち帰り、判断はあなたに委ねます。

## 自分だけのもの {#your-own}

Infinitary は、すでに契約している AI のサブスクリプションを使って、あなたのコンピューターで動きます。

- **あなたのコンピューター。**
  一等航海士、乗組員、そしてプロジェクトは、あなたのコンピューターにあります。
  作業は、あなた自身のプロジェクトの作業コピーで行われます。
- **あなたのサブスクリプション。**
  Infinitary は、すでに契約しているサブスクリプションを通じて動きます。
  クレジットも従量課金もありません：プロバイダーからの請求が、モデルの料金のすべてです。
- **あなたの記録。**
  どのタスクにも記録が残ります：何を頼んだか、何が変わったか、その根拠、そして何を決めたか。
