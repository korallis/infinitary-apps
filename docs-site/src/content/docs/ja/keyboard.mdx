Infinitary のすべての操作はキーボードで行えます。
Tab キーでコントロール間を移動し、リストの中は矢印キーで移動します。

## コマンド検索 {#command-search}

Mac では <kbd>⌘K</kbd>、Linux と Windows では <kbd>Ctrl+K</kbd> を押すと、コマンド検索が開きます。
言葉をいくつか入力し、矢印キーでコマンドを選んで Enter を押します。
このページのすべてのコマンドがそこにあり、キーのないものも含めて、それぞれのキーが横に表示されます。

## プリセット {#presets}

Infinitary には、プリセットと呼ばれるキーのセットが用意されています：Vim、Emacs、VS Code、Tmux、Legacy。
新しくインストールすると Vim から始まります。
Legacy は、プリセットができる前から Infinitary を使っていた場合にだけ表示されます。
プリセットは **設定** の **キーボード** で選びます。

## キーを変更する {#change-a-key}

**設定** の **キーボード** では、どのコマンドにも **記録**、**削除**、**リセット** があります。
**記録** を押し、使いたいキーを押してから、Enter を押して保存します。
そのキーを別のコマンドがすでに使っている場合は、何かが変わる前に、Infinitary がどのコマンドかを伝えます。

## すべてのコマンドとキー {#every-command-and-its-keys}

ダッシュは、そのコマンドにまだキーがないことを示します。コマンド検索から実行するか、好きなキーを割り当ててください。
間にスペースがある 2 つのキーは、順番に押します。
