パネルは、Infinitary のウインドウの横に並ぶ枠です。
パネルは、一等航海士との会話を挟んで、左と右の 2 つのパネル列に並びます。
表示するものがないパネル列は場所を取りません。

どのパネルにも、タイトルの入ったヘッダーがあります。
ヘッダーの矢印をクリックすると、パネルを折りたたんだり、また展開したりできます。
折りたたんだパネルでも、あなた待ちのタスクの数など、中身を短い言葉で示すことができます。

## アプリに備わっているパネル {#the-apps-own-panels}

Infinitary には次のパネルが備わっています。

- **アクティビティ**：左のパネル列のいちばん下にあります。
  一等航海士と乗組員がしていることを 1 行ずつ表示します。
- **タスク**：右のパネル列のいちばん下にあります。
  タスクを一覧にし、どれがあなたを待っているかを示します。
  **タスクを検索** ボタンでタスクを探し、**タスクボードを開く** でボード全体を開きます。
- **ナレッジ**：「タスク」の下にあります。
  一等航海士が守っている方針を表示し、**ナレッジを開く** で乗組員が学んだそのほかの内容を開きます。
  表示するナレッジができると現れます。
  [ナレッジ](/ja/knowledge/)を参照してください。
- **自動化**：「ナレッジ」の下にあります。
  自動化を一覧にし、それぞれが次にいつ実行されるかを示します。
  自動化を保存すると現れます。
  [自動化](/ja/automation/)を参照してください。

## パネルを並べ替える {#arrange-your-panels}

どのパネルも、左右どちらのパネル列の別の場所へも移動できます。

- **パネル列の上で。**
  パネルのヘッダーを押してドラッグします。
  移動先が線で示されます。
  そこで離すと移動し、それ以外の場所で離すと元に戻ります。
- **設定で。**
  **設定** を開き、**パネル** を開きます。
  一覧には、各パネル列の上部と下部のグループが順に表示されます。
  行をドラッグするとそのパネルが移動し、スイッチで表示・非表示を切り替えられます。
  **初期設定に戻す** を押すと、すべてのパネルが最初の位置に戻ります。
- **頼んで。**
  「タスクを左のパネル列に移して」のように、パネルを置きたい場所を一等航海士に伝えます。

非表示にしたパネルは **設定** の一覧に残るので、また表示できます。
パネル列の場所が足りなくなると、列の中央に近いパネルから先に折りたたまれます。
ヘッダーすら収まらない場合は、**ほか2件** のような行に残りが一覧表示されます。
そこで 1 つを選ぶと、パネル列に戻ります。

## キーボードを使う {#use-the-keyboard}

- F6 を押すと、パネルを含め、ウインドウの次の部分へ移動します。
  Shift+F6 で前に戻ります。
- ⌘, （Linux と Windows では Ctrl+, ）を押すと **設定** が開きます。

パネルによっては、**タスクを検索** や **ナレッジを開く** のような独自のコマンドが加わります。
これらはコマンド検索で見つかり、**設定** の **キーボード** でキーを割り当てられます。
[キーボード](/ja/keyboard/)を参照してください。

## 一等航海士が作るパネル {#panels-your-first-mate-builds-for-you}

自分だけのパネルを頼むこともできます。
「東京の天気を表示するパネルを作って」のように、何を表示するかを一等航海士に伝えます。
乗組員がアプリ自身の部品からパネルを作るので、Infinitary のほかの部分と同じ見た目になります。

乗組員がタスクを 3 つ終えると、左のパネル列のいちばん上に、空の **自分のパネルを作る** 枠が現れます。
クリックすると、メッセージ欄に依頼の書き出しが入ります。
その **隠す** をクリックすると、枠は今後表示されなくなります。

頼んだパネルは、場所を指定しない限り、左のパネル列のいちばん上に置かれます。
そのヘッダーには **あなたの** と表示されます。
ほかのパネルと同じように移動できます。
変更するには、どう変えたいかを一等航海士に伝えます。
なくすには、一等航海士に削除を頼みます。

## パネルをオフにする {#turn-your-panels-off}

**設定**、**一般**、**あなたのパネル** で、一等航海士が作ったパネルをすべてまとめてオフにできます。
アプリに備わっているパネルはそのまま残ります。
スイッチをオンに戻すと、あなたのパネルが戻ります。

起動直後に Infinitary が 2 回続けて終了した場合は、どれかのパネルが原因である場合に備えて、あなたのパネルが自動的にオフになります。
そのときは、スイッチにその旨が表示されます。
準備ができたらオンに戻してください。

あなたのパネルのどれかが動かなくなった場合は、そのパネルにその旨が表示され、ウインドウのほかの部分はそのまま動き続けます。
パネルのバックグラウンドの処理が応答しなくなったときは、その **再試行** ボタンで処理をもう一度開始できます。
