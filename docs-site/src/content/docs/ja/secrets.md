シークレットには、乗組員が作業に必要とするパスワードやキー（たとえば Web サイトを公開するためのキー）を保管します。
乗組員はシークレットを名前で使います。使えるのは、あなたがその使用を許可したときだけです。
各値はそのままこのコンピューターのシークレットに保管されます。Infinitary が再び表示することはなく、一等航海士にも乗組員にも渡りません。

## シークレットの保管場所 {#where-your-secrets-live}

**設定** を開いて **シークレット** を選ぶか、コマンド検索で **シークレットを開く** を探します。

**保護されたシークレット** には、各シークレットが名前と場所とともに一覧表示され、最後にどのタスクがいつ使ったかが示されます。
**シークレットを検索** では、名前、場所、または最後に使ったタスクからシークレットを探せます。

Mac では、一覧の下に「このコンピューターに保管されています。乗組員は使いますが、目にすることはありません。」と表示されます。
Linux と Windows では、乗組員はあなたの承認があるときだけ使いますが、システムのシークレット保管庫のロックが解除されている間は、あなたが実行するどのプログラムからでも届いてしまう、と表示されます。

シークレットは、一等航海士がいるコンピューターに残ります。
別の場所から一等航海士を操作するコンピューターには、独自のシークレットセクションはありません。

## シークレットを保管する {#keep-a-secret}

1. **シークレットを追加** を選びます。
2. **名前** を付けます（例：「Web サイトの公開」）。
3. **シークレットの値** に値を貼り付けます。
4. 同じ名前のシークレットを 2 つ保管する場合は、**場所（任意）** で区別します（例：staging や production）。
5. **シークレットを保存** を選びます。

保存後、値は隠されたままになり、あなたが許可した使用だけがそれを受け取れます。
シークレットの行を開くと、値を **置き換える** か、**登録を解除** できます。
登録を解除するとこのコンピューターから削除されますが、キーを作成した場所でキーが無効になるわけではありません。

### 保管していないシークレットが乗組員に必要なとき {#when-a-crewmate-needs-one-you-have-not-kept}

保管していないシークレットが必要な乗組員は、値ではなく名前でそれを頼みます。
すると Infinitary が独自のカードを表示します（例：「Web サイトの公開をシークレットに追加しますか？」）。カードには乗組員の理由が、乗組員自身の言葉で添えられます。
シークレットを自分で作成したり探したりする必要があるときは、カードに **入手方法** も表示されます。乗組員がこの場合のためにまとめた手順、名前、場所と、それを誰が書いたかを示す 1 行です。
そこでサインインする前に、表示された各アドレスを確認してください。

Infinitary がカード上に表示する隠しフィールドに各値を入力するか貼り付け、**シークレットを保存** を選びます。
**保存しない** を選ぶと、何も保存されません。
乗組員が受け取るのはシークレットの名前だけで、値は渡りません。また、使うたびにあなたに確認が求められます。

シークレットは、Infinitary が表示するフィールドにだけ入力してください。カードの返信欄やメッセージ欄には決して入力しないでください。

## 使用を許可する {#allow-a-use}

乗組員がシークレットを使おうとすると、Infinitary がカードを表示します（例：「Web サイトの公開シークレットを「サイトを公開」に渡しますか？」）。
カードには、何がそれを受け取るのかが正確に示されます。

- **シークレット**：各シークレットと、プログラムがそれを受け取るときの名前。
- **実行**：実行されるコマンドそのもの。
- **フォルダー**：実行される場所。
- **理由**：乗組員自身の言葉による理由。

**確認したことすべて** には、Infinitary がプログラムについて確認したことと、確認できなかったことが一覧表示されます。
そのうえで、次のどれかを選びます。

- **今回のみ許可** は、今回の実行にだけシークレットを渡します。
- **常に許可** は、今回の実行に渡したうえで、この実行をそのまま保存します（同じプログラム、ファイル、引数、フォルダー）。
  少しでも違えば、もう一度確認されます。
- **許可しない** は拒否します。次の実行ではもう一度確認されます。

どの許可も、先に確認を求めます。Mac では Touch ID またはパスワード、Linux ではパスワード、Windows では Windows Hello または Windows のパスワードで確認します。
シークレットを受け取った側は、それを保持できます。
許可しても、デプロイや送信などの別の操作が承認されることはありません。
乗組員に伝わるのは実行が終わったかどうかだけで、何が出力されたかは伝わりません。

リクエストが待機している間は、設定 → シークレットの一番上にそれが表示され、**リクエストを確認** でカードを開けます。

## 保存された判断 {#saved-decisions}

シークレットの一覧の下にある **アクセス・履歴・復元** を開き、**保存された判断** を開きます。
**常に許可** で保存した判断が、それぞれ 1 文で一覧表示されます。

判断を保存できるのは、リクエストのカード上だけです。
ここでは判断を **削除** できます。コンピューターが確認を求め、次に使うときには乗組員がもう一度あなたに確認します。

## スマートフォンから承認する {#approve-from-your-phone}

コンピューターから離れているときも、iPhone や iPad から使用を許可できます。

1. 設定 → **デバイス** で、スマートフォンの行の **シークレットの使用を承認** をオンにします。
2. スマートフォンで Infinitary を開くと、コードが表示されます。
3. **コードを比較** を選び、コンピューターのカードに表示されたコードがスマートフォンの設定に表示されたコードと一致することを確かめます。
4. コンピューターで **確認して許可** を選ぶと、確認を求められます。

それ以降、スマートフォンのリクエストカードには **今回のみ許可** と **許可しない** が表示されます。
許可するたびに、Face ID、Touch ID、またはスマートフォンのパスコードが求められます。
ある実行を常に許可する判断は、コンピューターにだけ保存されます。
別の場所から一等航海士を操作する Mac でも使用を承認できます。設定方法は同じで、その Mac の行から行います。

やめるには、スイッチをオフにするか、**アクセス・履歴・復元** の **承認するデバイス** で **承認を停止** を選びます。

## 別のツールからシークレットを移す {#move-secrets-from-another-tool}

Automic Vault、.env ファイル、Mac のキーチェーンなど、別のツールにシークレットを保管している場合は、乗組員が値を見ることなくそれをシークレットに取り込めます。

1. 設定 → シークレットで **別のツールから移す** を選ぶか、コマンド検索で **別のツールからシークレットを移す** を選びます。
2. メッセージ欄に一等航海士への依頼が入力されるので、ツールの名前を書き添えて送信します。
3. 乗組員がカードを表示します（例：「Automic Vault から 3 件のシークレットを取り込みますか？」）。カードには、実行するコマンドまたは読み込むファイルと、その理由が示されます。
4. 保管するシークレットにそれぞれチェックを入れ、**シークレットに取り込む** か **取り込まない** を選びます。

コマンドの実行やファイルの読み込みは Infinitary 自身が行い、チェックを入れたものだけを保管します。
.env ファイルなどのファイルの場合は、まず **読み込む** で、中にある名前が一覧表示されます。
乗組員が受け取るのは名前だけで、値は決して渡りません。別のツール内のコピーもそのまま残ります。
シークレットを選ぶのは、一等航海士がいるコンピューターの Infinitary のウインドウで、スマートフォンでは選べません。

## 連携のキー {#keys-for-your-integrations}

設定 → **連携** で Google にサインインしたり、キー付きの MCP サーバーを追加したりすると、Infinitary はそのキーをシークレットに保管します。
シークレットでは、それらのキーに「置き換える」と「登録を解除」の代わりに **連携で管理** が表示されます。
サインインすること、またはキー付きでサーバーを追加することがあなたの同意なので、Infinitary は確認せずにそれらを使います。
乗組員はそれらを見ることも、使用を頼むこともできません。
登録を解除するには、連携でサインアウトするか、サーバーを削除します。
[連携](/ja/integrations/)を参照してください。

## 使用履歴とバックアップ {#use-history-and-backups}

**使用履歴** には、使用ごとに、どのシークレットか、理由、プログラム、どのように許可されたか、どう終わったかが一覧表示されます。値が表示されることはありません。
履歴は削除するまで残り、**履歴を書き出す** と **履歴を削除** が使えます。

**バックアップと復元** には **暗号化したバックアップを保存** があり、暗号化したコピーと、それとは別の復元キーを保存します。
この 2 つは別々に保管してください。両方を持つ人は誰でも保存された値を読めます。また、キーのリセットはできません。
**バックアップから復元** は保管されている値を置き換え、保存された判断、スマートフォンでの承認、一時的なアクセスを消去します。

## シークレットを開けないとき {#when-secrets-cannot-open}

コンピューターのシークレット保管庫がロックされている場合、シークレットには **ストレージはロック中** と表示され、**ロック解除または再確認** が使えます。
リクエストは、保管庫が開くまで待機し続けます。

保管した内容を Infinitary が読めなくなった場合、シークレットには **復元が必要です** と表示され、使用は一切許可されません。
**復元オプション** を押すと **バックアップと復元** が開き、バックアップから復元できます。
**最初からやり直す** は、保管されたシークレット、保存された判断、スマートフォンでの承認、一時的なアクセスを消去します。この操作は取り消せません。

## サインイン済みのサイト {#signed-in-sites}

シークレットの一番下には **サインイン済みのサイト** が一覧表示されます。タスクのブラウザでサインインしたサイトです。
これらは保護されたストレージではなく、そのコンピューターのブラウザプロファイルに残ります。
[乗組員のブラウザ](/ja/the-crews-browser/#signed-in-sites)を参照してください。

## 一等航海士が移るとき {#when-your-first-mate-moves}

一等航海士が別のコンピューターに移ると、シークレットは移動元のコンピューターに残るので、移動先でもう一度追加します。

[一等航海士のコピーを置いている](/ja/your-other-computers/#keep-a-copy-on-another-computer)コンピューターには、シークレットも置いておけます。
設定 → **デバイス** で、そのコンピューターの **引き継ぎの準備状況** の一覧にある **そこにシークレットを置く** を選び、そのコンピューター自身で確認します。
あとで一等航海士がそこへ移るか、[そのコピーから起動する](/ja/your-other-computers/#take-over)と、値も一緒に引き継がれます。
そのコンピューターにすでに独自のシークレットがある場合は、どちらを使うかをそこでカードが尋ねます。
保存された判断や承認するデバイスは引き継がれないので、使うたびにもう一度確認が求められ、スマートフォンも設定し直します。

[ほかのコンピューター](/ja/your-other-computers/#move-your-first-mate)、[コンピューターの外に出るもの](/ja/what-leaves-your-computer/#secrets)も参照してください。
