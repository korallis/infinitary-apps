一等航海士は、Infinitary で話しかける相手です。
ウインドウの中央に描かれていて、乗組員を率いています。

## 一等航海士がすること {#what-your-first-mate-does}

- メッセージを読み、必要なものが回答か、あなたへの質問か、作業かを判断します。
- 自分で答えられる質問には、カードで答えます。
- 作業をタスクにし、それぞれに乗組員を割り当てて開始します。
- すべてのタスクを把握し、あなたの言葉を乗組員に伝え、終わった作業を閉じます。
- あなたの判断が必要なときは、カードを届けます。

## 乗組員に任せること {#what-it-leaves-to-the-crew}

一等航海士は、あなたのファイルを編集したり、コードを読んだり、プロジェクトで何かを実行したりしません。
プロジェクトのファイルが必要なこと、ビルド、問題の原因の調査は、すべて乗組員に任されます。
乗組員はそれぞれプロジェクトの自分用の作業コピーで作業するので、あなた自身のファイルはそのまま保たれます。
[タスクと乗組員](/ja/tasks-and-crewmates/)を参照してください。

## 一等航海士に話しかける {#talking-to-your-first-mate}

ウインドウ下部のメッセージ欄に入力して送信します。
あなたのメッセージと一等航海士の短い返事は、欄のすぐ上に表示されたままになります。
返事をクリックすると、全文を読めます。

次のことが役に立ちます。

- **どこからでもメッセージ欄に移動する。**
  ⌘L（Linux と Windows では Ctrl+L）を押します。
- **最後のメッセージを呼び戻す。**
  空のメッセージ欄で ↑ を押します。
- **長い文章を貼り付ける。**
  長い文章を貼り付けると欄の中でファイルの形になり、メッセージと一緒にそのまま全部送られます。

### 画像やファイルを追加する {#add-pictures-and-files}

ファイルをメッセージ欄にドラッグするか、**ファイルを追加** を押します。
画像とテキストファイルは、それぞれ 4 つまでメッセージと一緒に送られます。
PDF などそれ以外の種類のファイルは、コンピューター上のファイルの場所が文字として欄に加えられ、乗組員がそこで開けるようになります。

### 入力の代わりに話す {#talk-instead-of-typing}

音声入力のキーを押すか、押し続けて話します。
メッセージ欄のヒントにそのキーが示されています：「入力するか、右 ⌥ を押す／押し続けて話す」。
Linux と Windows では、キーは右 Ctrl です。
話した内容はコンピューター上で文字に変換され、送信する前に編集できます。
キーを変えたり音声入力をオフにしたりするには、[設定 → 一般](/ja/settings/#general)の **音声入力** を使います。

### カードで答える {#answer-it-on-a-card}

一等航海士や乗組員がカードを届けたときは、そのカード自体で答えます。
カードの下に入力した内容は、カードを書いた相手に届きます。
[カードと判断](/ja/cards-and-decisions/)を参照してください。

## モデルを選ぶ {#choosing-its-model}

一等航海士は、あなたのサブスクリプションのいずれかを通じて答えます。
モデルを選ぶには、設定 → インテリジェンスを開き、**一等航海士のモデル** を使います。
**自動（サブスクリプションから）** を選ぶと、サブスクリプションで使えるものの中から Infinitary が選びます。
変更は、次に一等航海士が手すきになったときに反映されます。

同じプロバイダーのアカウントが 2 つある場合、行の名前は **一等航海士のモデルとアカウント** になり、アカウントも選べます。
乗組員の作業では別のアカウントを優先させることもできます。そのアカウントのメニューで **乗組員の作業で優先** を使います。
[サブスクリプションと利用枠](/ja/subscriptions-and-quota/)を参照してください。

プランの利用枠を使い切ったなどの理由で、一等航海士が使っているサブスクリプションが応答しなくなった場合、一等航海士はその理由とできることを書いたカードを 1 枚表示します。
その間に送ったメッセージは保持され、再び答えられるようになったときに届きます。

## コンピューターの電源を入れておく {#keep-its-computer-on}

一等航海士は 1 台のコンピューターにいます。
スマートフォンやほかのコンピューターは、そこにいる一等航海士にアクセスします。
できるだけ電源が入ったままのコンピューターに設定してください。

そのコンピューターがスリープ中か、そこで Infinitary が閉じていると、一等航海士は答えられません。
サインイン時に Infinitary を開くには、設定 → 一般で **サインイン時に起動** をオンにします。

ほかの場所から一等航海士にアクセスするには、[ほかのコンピューター](/ja/your-other-computers/)と[iPhone と iPad](/ja/iphone-and-ipad/)を参照してください。
