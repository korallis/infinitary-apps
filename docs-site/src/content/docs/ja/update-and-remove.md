Infinitary は数時間ごとに新しい安定版を確認します。
確認しても何もダウンロードされず、あなたが選ぶまで何もインストールされません。
アップデートしても、保存した作業はそのまま残ります。

## 新しいバージョンが出たとき {#when-a-new-version-is-out}

ウインドウの右上に、下向き矢印の付いた丸いボタンが表示されます。
ポインタを重ねると「アップデートがあります」と新しいバージョンの番号が表示され、押すと次にすることがわかります。
設定 → **一般** の **バージョン** にも同じ内容が表示されます。

自分で確認するには、次のどれかを使います。

- 設定 → **一般** の **バージョン** にある **アップデートを確認**。
- コマンド検索の **アップデートを確認**。
- Mac では、Infinitary メニューの **アップデートを確認…**。

次にすることは、Infinitary をどのようにインストールしたかによって変わります。

## ダウンロードページから入手した Mac 版 {#a-mac-copy-from-the-downloads-page}

1. **アップデートして再起動** を押します。
2. Infinitary が新しいバージョンをダウンロードし、チェックサムと Apple の署名を確認します。
3. 乗組員の作業を保存します。
   実行中の作業は今実行しているものを先に終えるので、何も失われません。
4. Infinitary が新しいバージョンで再起動し、アップデートのために一時停止していた作業を再開します。

実行中の作業を待っている間に **後でアップデート** を押すと、もう一度選ぶまでアップデートを見送れます。
作業はそのまま続きます。

Infinitary が再起動を完了できなかった場合、ボタンは **再起動** に変わります。
実行中の作業が止まったら、もう一度押してください。

Infinitary が自分でアップデートできるのは、「アプリケーション」フォルダーから起動しているときだけです。
ディスクイメージから起動している場合は、「アプリケーション」フォルダーにドラッグし、ディスクイメージを取り出してから、「アプリケーション」フォルダー内のものを開いてください。

## Homebrew で入手した Mac 版 {#a-mac-copy-from-homebrew}

Homebrew でインストールしたものは、Homebrew でアップデートします。
お知らせにはコマンドと **コマンドをコピー** が表示されます。

```sh wrap
brew update && brew upgrade --cask infinitary-labs/tap/infinitary
```

これを「ターミナル」で実行します。
Homebrew は置き換えの間 Infinitary を終了させるので、終わったら Infinitary をもう一度開いてください。

## Linux {#linux}

- **Ubuntu、Debian、Fedora**（.deb または .rpm パッケージから入手した場合）：**インストール** を押します。
  Infinitary が新しいバージョンをダウンロードして確認し、乗組員の作業を保存してパスワードを求めたあと、再び起動します。
- **AppImage**：**インストール** を押します。
  Infinitary が AppImage ファイルを新しいバージョンに置き換えて再び起動します。パスワードは不要です。
  AppImage があるフォルダーを変更できる必要があります。
- **Arch、Omarchy、NixOS** は、それぞれのパッケージマネージャーでアップデートします。
  お知らせにはコマンドと **コマンドをコピー** が表示されるので、ターミナルで実行します。

インストールを完了できなかった場合は何も変わらず、乗組員の作業もそのまま続きます。
その場合、お知らせには同じバージョンを手動でインストールするコマンドが表示されます。

## Windows {#windows}

1. **アップデートして再起動** を押します。
2. Infinitary が新しいインストーラーをダウンロードしてチェックサムを確認し、乗組員の作業を保存します。
3. Infinitary が閉じ、インストーラーが置き換えたあと、新しいバージョンの Infinitary が再び開きます。

インストールを完了できない場合は何も変わらず、乗組員の作業はそのまま続きます。

## ほかのコンピューターとスマートフォン {#your-other-computers-and-your-phone}

追加したコンピューターは、一等航海士がいるコンピューターからアップデートされます。
設定 → **デバイス** では、バージョンが異なるコンピューターの行に **更新** が表示されます。
そのコンピューターはこのコンピューターと同じバージョンになり、実行中の作業は少しの間止まって、そのあと続きます。

一等航海士を操作するコンピューターでは、設定 → **一般** に、一等航海士がいるコンピューターの Infinitary の行があります。
そのコンピューターでアップデートの準備ができたら、**更新** とその名前が書かれたボタンを押すと、今いる場所からアップデートを開始できます。
スマートフォンからも、先に確認したうえでそのアップデートを開始できます。
[ほかのコンピューター](/ja/your-other-computers/)、[iPhone と iPad](/ja/iphone-and-ipad/)を参照してください。

## Infinitary を削除する {#remove-infinitary}

アプリを削除しても保存した作業はそのまま残るので、Infinitary をもう一度インストールすれば続きから始められます。
このコンピューターがほかのコンピューターの作業を実行している場合は、先に設定 → **デバイス** で **離脱** を押してください。

- **ダウンロードページから入手した Mac 版**：Infinitary を終了し、「アプリケーション」フォルダーからゴミ箱に移します。
- **Homebrew で入手した Mac 版**：「ターミナル」で `brew uninstall --cask infinitary` を実行します。
  `--zap` は決して付けないでください。保存した作業が削除されます。
- **Linux**：インストールに使ったソフトウェアインストーラーまたはパッケージマネージャーで、パッケージを削除します。
  AppImage の場合は、ファイルを削除します。
- **Windows**：Windows の設定 → **アプリ** → **インストールされているアプリ** で、Infinitary のメニューから **アンインストール** を選びます。

保存した作業は、Mac では `~/Library/Application Support/infinitary`、Linux では `~/.config/infinitary`、Windows では `%APPDATA%\infinitary` に残ります。

### 保存した作業が削除される操作 {#what-deletes-your-saved-work}

次の操作はそのフォルダーを削除し、Infinitary がそこに保存していたものも一緒に消えます：

- `brew uninstall --zap`。
- アプリのサポートファイルも削除するアンインストーラーアプリ。
- フォルダーそのものをゴミ箱に入れる、または削除する。

ほかのコンピューターのために作業を実行するコンピューターでは、そのフォルダーにコンピューター自身の鍵、作業コピー、タスクのファイルが入っています。
それがなくなると、コンピューターは新しい項目としてもう一度参加し、まだ持ち帰っていなかった作業は失われたままになります。
[同じコンピューターが 2 つ表示される](/ja/troubleshooting/#a-computer-is-listed-twice)を参照してください。
