Infinitary は、すでに持っているサブスクリプションを通じて、あなたのコンピューター上で動きます。
私たちのアカウントは必要なく、作業が私たちを経由することもありません。
このページでは、アプリが何をどこへ送るかを一覧にしています。

## 作業は選んだプロバイダーへ送られる {#your-work-goes-to-the-provider-you-chose}

一等航海士と乗組員は、サインインした AI のサブスクリプションを通じて考えます。
メッセージと、乗組員がタスクのためにプロジェクトから読む内容は、サブスクリプションを通じてそのプロバイダーへ送られます。
Claude の場合、Infinitary はインストール済みの Claude Code を、あなた自身のアカウントにサインインした状態で使います。
カスタムのプロバイダーの場合は、入力したアドレスへ送られます。

サインインはコンピューターに残ります。

## プロジェクトは保管先へ送られる {#your-projects-go-where-they-live}

乗組員は、コンピューター上にあるプロジェクトの作業コピーで作業します。
タスクがプルリクエストとして提示されると、そのブランチが GitHub、GitLab、Bitbucket などのプロジェクトの保管先へプッシュされ、そこでプルリクエストが作成されます。
このコンピューターだけに置いているプロジェクトは、このコンピューターから出ません。

乗組員が作業コピーを用意するときやタスクを行うときは、あなたが手作業でするのと同じように、プロジェクトに必要なものを取得することがあります。

## ほかのコンピューターとスマートフォン {#your-other-computers-and-your-phone}

追加したコンピューターやスマートフォンは、一等航海士がいるコンピューターと通信します。
設定 → **デバイス** に、それらがそのコンピューターを見つける方法が表示されます。
**インターネット経由** には「使いません。Infinitary はこのコンピューターをインターネットに公開しません。」と表示されます。

別のコンピューター用に入力したサインインは、そのコンピューターへ 1 回だけ送られます。
一等航海士がいるコンピューターにはコピーが残りません。
[ほかのコンピューター](/ja/your-other-computers/)を参照してください。

## 接続した連携 {#integrations-you-connect}

設定 → **連携** で接続した Google などの連携には、その連携自身のサインインでアクセスします。そのサインインは、サインインしたコンピューターに残ります。
一等航海士と乗組員がそれを読むのは、接続したあとだけです。
[連携](/ja/integrations/)を参照してください。

## 会社の使用量レポート {#your-companys-usage-reporting}

Claude Code の設定ファイルやシェルで、Claude Code のガイドどおりに会社向けの使用量レポートを設定している場合、Infinitary はここで行ったすべての作業の使用量を同じ送信先に送ります。
Claude の作業は、Claude Code 自身がそこに送るのと同じ記録として送られます。
ほかのモデルの作業は同じ名前で、モデル、プロバイダー、トークン、推定コスト、一等航海士とクルーのどちらが行ったか、作業の種類、Claude Code のサインインのメールアドレスとともに送られます。
あなたの言葉、タスクのタイトル、プロジェクト名は送られません。
設定 → **使用量** に送信先が表示されます。
その送信先が Claude の作業を拒否し続けたり、到達できなかったりすると、その行が代わりにそのことを伝えます。
会社の管理者がコンピューター全体に対して管理している設定は、これまでどおり Claude Code に直接届き、Infinitary はほかのモデルの作業も同じようにそこへ送ります。
どちらの設定も、使用量を gRPC で送る場合は Claude の作業だけが届き、そのときは 設定 → **使用量** にもそう表示されます。

## アップデートの確認 {#update-checks}

Infinitary は数時間ごとに、リリースが公開されている場所で新しいバージョンがないかを確認します。
この確認では、あなたの内容も ID も送られません。
毎日最初の確認と、毎月最初の確認では、それが最初であることもあわせて伝え、Infinitary Labs が Infinitary を使っているコンピューターの台数を数えられるようにしています。
これは **診断** スイッチの状態にかかわらず行われますが、Homebrew でインストールしたものでは送られません。
新しいバージョンをダウンロードするのは、アップデートを選んだときだけです。
自分で **アップデートを確認** を押すこともできます。
[Infinitary のアップデートと削除](/ja/update-and-remove/)を参照してください。

## 音声入力 {#dictation}

音声入力は、あなたの声をコンピューター上で文字に変えます。
初めて使うときは、音声モデルを 1 回だけダウンロードする前に確認を求めます。

## 診断：私たちに送る唯一のスイッチ {#diagnostics-the-one-switch-that-sends-to-us}

設定 → **一般** → **共有** に **診断** スイッチがあります。
これは私たちに何かを送る唯一のスイッチです。これがなくても私たちに届くのは、上で説明したアップデート確認の「その日最初」「その月最初」の知らせだけで、これについても **共有** に説明があります。
オフにしない限りオンになっていますが、アプリのどの機能もこれに依存していません。

初めて起動したときは、メッセージ欄の下に送信内容を説明するお知らせが表示され、**オフにする** と **OK** が並びます。
答えるまで何も送信されません。

診断は、匿名の使用状況イベントを送ります。

- アプリが開いたこと
- 一等航海士がターンを終えたこと、または失敗したこと（失敗の種類だけ）
- 初回設定がどこまで進んだか
- 追加した iPhone や iPad からの、アプリが開いたこと、設定されたこと、メッセージが送られたこと、カードに回答したこと

各イベントには、アプリのバージョンとランダムなインストール ID が含まれます。
この ID はあなたやコンピューターに関する何とも結びついておらず、診断をオフにしてからオンに戻すたびに新しくなります。
あなたが書いたテキスト、名前、パスは送られません。会話、コード、カードが送られることも決してありません。
スマートフォン自体は何も送りません。コンピューターが、同じスイッチのもとでスマートフォンのイベントを送ります。

何が送られるのかを正確に確認するには、**共有** の下にある **このコンピューターから送られる内容** を開きます。
インストール ID、送信待ちの内容、送信済みの内容、そして診断が送る可能性のあるすべてのイベントが表示されます。
**診断** をオフにすると、それ以降は何も記録も送信もされません。

## シークレット {#secrets}

設定 → **シークレット** に保管した値は、コンピューターに残ります。
それぞれの値はそのままシークレットに入ります。Infinitary がそれを再び表示することはなく、一等航海士も乗組員もその値を受け取りません。
[シークレット](/ja/secrets/)を参照してください。
