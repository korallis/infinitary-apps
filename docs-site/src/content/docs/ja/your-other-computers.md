一等航海士は 1 台のコンピューターにいます。
タスク、カード、会話はそこに残ります。
追加したどのコンピューターからでも一等航海士を操作でき、追加したどのコンピューターでもプロジェクトの作業を実行できます。

これらはすべて、設定 → **デバイス** の **あなたのデバイス** にあります。
設定は ⌘, （Linux と Windows では Ctrl+, ）で開きます。

## 一等航海士がいるコンピューター {#the-computer-where-your-first-mate-lives}

できるだけ電源が入ったままのコンピューターを選んでください。
ほかのコンピューターやスマートフォンからは、このコンピューターがスリープしておらず、Infinitary が開いている必要があります。

スリープ中や連絡がつかない間は、次のようになります。

- ほかのコンピューターには最後に見えた状態が表示され、「変更できません」と表示されます。
  そこで入力したメッセージは送信されず、そのコンピューターが戻るまで、入力した言葉はメッセージ欄に残ります。
- 自動化は、そのコンピューターで Infinitary が開いていて、スリープしていない間だけ実行されます。
  その間に実行されなかった分は、戻ったときに 1 回だけ実行されます。

## コンピューターを追加する {#add-a-computer}

1. 一等航海士がいるコンピューターで、設定 → **デバイス** を開きます。
2. **+ コンピューター** を押します。
3. もう一方のコンピューターのアドレスを入力し、**追加** を押します。

まずはアドレスでコンピューターを追加する方法を使うと、このコンピューターがもう一方を最新に保って自分で接続するので、設定後にそちらへ出向く必要はありません。
もう一方のコンピューターに SSH で接続するときのアドレスを入力します（例：`you@mini.local`）。
そのコンピューターで「リモートログイン」がオンになっている必要があります。Linux の場合は SSH サーバーが必要です。
同じネットワーク上のコンピューターは **このネットワーク上** に一覧表示されるので、そこから選べます。
一等航海士にコンピューターの追加を頼むこともでき、一等航海士がアドレスを勧めてくれます。

新しい Mac や x64 の Linux コンピューターでは、Infinitary の初回起動時に **一等航海士のコンピューターから設定する** を選ぶと、入力するアドレスが表示されます。
まず Tailscale などのこのコンピューターのプライベートネットワークのアドレスが、次にローカルネットワーク上のアドレスが、それぞれ **コピー** 付きで表示されます。
一等航海士がいるコンピューターがこのコンピューターを追加すると、そのウインドウでまだ何も設定していなければ、そのウインドウが自動で一等航海士を開きます。
すでにサインインした、プロジェクトを追加した、またはその一等航海士と話したウインドウは自分の一等航海士のままで、「ターミナル」から自分で起動した Infinitary の横にあるウインドウも同じです。
追加されたときにそのコンピューターで Infinitary が閉じていた場合は、何を設定していても、次に起動したときに一等航海士を開きます。
Windows PC と Arm の Linux コンピューターは、代わりに **リンクを貼り付ける** で参加します。

アドレスの下の **そちらで「リモートログイン」をオンにできませんか？** から、ほかの 2 つの方法を使えます。
どちらの方法でも、追加されるコンピューターの種類は同じです。

**そちらの Infinitary にリンクを貼り付ける** は、そのコンピューターの前にいるときや、それが Windows PC のときに使います。
リンクをコピーし、もう一方のコンピューターで Infinitary を初めて開きます。
**一等航海士は別のコンピューターにいます** の下で **リンクを貼り付ける** を選び、リンクを貼り付けて **続ける** を押します。
Infinitary が、そこから一等航海士を操作するかどうかを 1 回だけ尋ねるので、**ここから操作する** を押します。

**そちらでコマンドを実行する** は、そちらの「ターミナル」で入力はできるものの「リモートログイン」がオフのときに使います。
コマンドをコピーし、もう一方のコンピューターの「ターミナル」で、作業を実行させたいユーザーとして 1 回実行します。
このコマンドは Infinitary をこのコンピューターから取得するため、両方が同じネットワークにある必要があります。

一等航海士が Windows PC にいる場合、**+ コンピューター** にはリンクとコマンドだけが表示されます。

リンクやコマンドは 1 回だけ、10 分間使えます。それまでに **停止** を押して無効にすることもできます。
もう一方のコンピューターから参加することもできます。初回起動時に **アドレスで参加** を選び、一等航海士がいるコンピューターのアドレスを入力します。

## 別のコンピューターから一等航海士を操作する {#control-your-first-mate-from-another-computer}

コンピューターが参加すると、そこで Infinitary を開けば一等航海士が表示されます。
ウインドウの上部には「一等航海士を操作中：」と、そのコンピューターの名前が表示されます。
カード、タスク、会話は、一等航海士がいるコンピューターに残ります。

外観、キーボード、パネルの設定は、コンピューターごとに別々に保たれます。
そのほかの設定セクションは、一等航海士がいるコンピューターの設定を表示・変更します。

操作をやめるには、そのコンピューターで設定 → **デバイス** を開き、**離脱** を押します。
一等航海士がいるコンピューターからあるコンピューターを切り離すには、そのメニュー（行の右にある 3 つの点）を開いて **削除** を選びます。
一等航海士を操作するだけのコンピューターが戻ってくるには、新しいリンクが必要です。

## 作業を実行するコンピューター {#a-computer-that-runs-work}

追加したコンピューターはどれも、ウインドウを開いていなくてもプロジェクトの作業を実行できます。
そのコンピューターは自分のサブスクリプションにサインインし、そこで実行されるタスクはそのサブスクリプションだけを使います。
設定 → **インテリジェンス** でサブスクリプションにサインインさせます。各コンピューターのサインインは、その名前の下に一覧表示されます。
次に、プロジェクトを割り当てます。

設定 → **プロジェクト** でプロジェクトを開き、**実行先** を **自動**、**このコンピューター**、または **あなたのコンピューター** のいずれかに設定します。
そのコンピューターと連絡がつかない間、プロジェクトのタスクは待機し、代わりにこのコンピューターで実行されることはありません。

一等航海士がいるコンピューター上の別のユーザーとして作業を実行することもできます。
**+ 別のユーザーとして実行** を押すと、そのためのコマンドが作られます。

作業を実行するコンピューターを削除すると、まだマージされていない作業が先に戻されます。

## タスクを別のコンピューターへ移す {#move-a-task-to-another-computer}

開始済みのタスクは、作業を実行する別のコンピューターへ移せます。
タスクの記録を開いて **コンピューターへ移す** を押し、移動先を選びます。
タスクキー、ブランチ、ファイル、記録はそのまま引き継がれます。
タスクは、担当の乗組員が今している作業を終えたところで移動します。それまでは **移動をキャンセル** を押せます。

## 別のコンピューターにあるファイル {#files-on-another-computer}

乗組員は、ほかのコンピューターにあるファイルを読むために、タスクへコピーできます。
読むだけです。ほかのコンピューターに何かが書き込まれることはありません。
コピーするたびに、タスクのアクティビティに 1 行が加わり、ファイル名とコピー元のコンピューターが記されます。

## 一等航海士を移す {#move-your-first-mate}

作業を実行するコンピューターのメニュー（行の右にある 3 つの点）で **一等航海士をここへ移す** を選ぶと、一等航海士がそこへ移ります。
最初に、移動の妨げになるものが一覧で表示されます。
[シークレット](/ja/secrets/)は移動元のコンピューターに残り、移動先ではサブスクリプションにもう一度サインインします。

## 別のコンピューターにコピーを置く {#keep-a-copy-on-another-computer}

作業を実行するコンピューターには、一等航海士の記録のライブコピーを置いておけます。
そうしておけば、一等航海士がいるコンピューターが失われたり、長く連絡がつかなくなったりしたときに、そのコンピューターが[引き継ぐ](#take-over)ことができます。

1. 一等航海士がいるコンピューターで設定 → **デバイス** を開き、もう一方のコンピューターを選びます。
2. そのメニュー（行の右にある 3 つの点）を開いて **ここにコピーを置く** を選びます。

まず完全なコピーを 1 回作り、その後は一等航海士が保存する変更を 1 つずつ受け取ります。
行にはコピーの状態が表示されます（例：**コピーは最新です**、**コピーを同期中 · 変更3件**）。連絡がつかない間は、時刻を添えて **〜時点のコピー** と表示されます。
コピーは複数のコンピューターに置けます。

コピーには、一等航海士のタスク、カード、会話、ナレッジ、自動化が含まれます。
そのコンピューターは、引き継ぐまでコピーを開きません。
コピーそのものには、プロジェクト、サインイン、シークレットは含まれません。

- 引き継ぐときに、各プロジェクトはその保管先からもう一度クローンされます。
  失われたコンピューターにしかなかったプロジェクトは、引き継ぎ先では空の状態から始まります。
- メニューの **引き継ぎの準備状況** には、そのコンピューターにまだ必要なものが一覧表示されます。たとえば、一等航海士が使う各サブスクリプションやプロジェクトの保管先への、そのコンピューター自身のサインインです。
  それぞれのボタン（例：**そこで GitHub にサインイン**）を押すと、このウインドウからそのサインインを始められます。
- 同じ一覧の **そこにシークレットを置く** を使うと、そのコンピューター自身で確認したあとに、シークレットをコピーと一緒に置いておけます。
  [シークレット](/ja/secrets/#when-your-first-mate-moves)を参照してください。

その一覧の **コピーを置くのをやめる** を押すとコピーの保持が終わり、そのコンピューターは連絡がついた時点でコピーを削除します。

マージ、プッシュ、シークレットの使用の前に、一等航海士は、連絡がつくすべてのコピーがそれまでの変更をすべて受け取るまで待ちます。
そのため、引き継いだコンピューターはすでに行われたことを把握していて、同じことを繰り返しません。

## 引き継ぐ {#take-over}

一等航海士がいるコンピューターと連絡がつかない間は、コピーを置いているコンピューターが引き継げます。一等航海士はそのコピーからそこで起動します。
勝手に引き継がれることはなく、タイマーで決まることもありません。引き継ぎはあなたのクリックだけで行われます。

コピーを置いているコンピューターで Infinitary を開き、設定 → **デバイス** を開きます。
**操作中** の下の **引き継ぐ** には、このコピーがいつの時点のものか、また一等航海士のコンピューターがスリープに入ると伝えてきたか、そこで Infinitary が終了したかが表示されます。
ほかのコピーも一覧表示され、より多くの変更を含んでいる可能性があるものには **より新しい可能性** と表示されます。
より新しいコピーに連絡がつく場合は、このコンピューターが先にそれを取り込みます。

1. **引き継ぐ** を押します。
2. もう一度 **引き継ぐ** を押して確定するか、**とどまる** を押して今のままにします。
3. Mac では Touch ID またはパスワードで、Windows PC では Windows Hello または Windows のパスワードで確認します。

すると一等航海士がこのコンピューターで起動し、ここが一等航海士のいるコンピューターになります。
ほかのコンピューターやスマートフォンは、新しいリンクなしで自動的にここを見つけます。
足りないサインインはそこでカードが一つずつ求めます。シークレットは、コピーと一緒に置いていなかった場合はもう一度追加します。

スマートフォンから、コンピューターに引き継ぎを頼むこともできます。
コンピューターと連絡がつかない間に、スマートフォンの上部バーの右にあるコンピューターのボタンをタップします。
表示されるシートで、コピーを置いている各コンピューターについて **引き継ぐ** を選べます。その後、Face ID またはパスコードを求められます。

### 失われたコンピューターが戻ってきたら {#if-the-lost-computer-comes-back}

失われていたコンピューターは、戻ってきた時点で一等航海士のコンピューターではなくなり、代わりにコピーを置くようになります。
その設定 → **デバイス** の **引き渡し済み** の下には、コピーのあとにそのコンピューターが保存した、一等航海士には届かなかった内容が一覧表示されます。
その記録は別に取っておかれ、再び開かれることはありません。

2 台のコンピューターがどちらも一等航海士として応答した場合は、設定 → **デバイス** の **2 人の一等航海士** で、**こちらを残す** か、もう一方を残すかを尋ねられます。
選ぶまでマージ、プッシュ、シークレットの使用は待機し、残さなかったほうは停止して、もう一方のコピーを置くようになります。

## コンピューター同士が見つけ合う仕組み {#how-computers-find-each-other}

設定 → **デバイス** には **ほかのデバイスがこのコンピューターを見つける方法** として、**このネットワーク上** と **プライベートネットワーク上** が表示されます。
**インターネット経由** には「使いません。Infinitary はこのコンピューターをインターネットに公開しません。」と表示されます。
別の場所から一等航海士を操作するには、両方のコンピューターを同じプライベートネットワークに入れてください。

[iPhone と iPad](/ja/iphone-and-ipad/)、[トラブルシューティング](/ja/troubleshooting/)も参照してください。
