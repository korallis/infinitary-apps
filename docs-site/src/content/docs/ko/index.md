Infinitary는 나만의 AI 스튜디오예요.
macOS, Linux, Windows용 데스크톱 앱이에요.
일등항해사 한 명과 이야기하면, AI 선원들이 일을 해요.

## 작업이 진행되는 방식 {#how-a-task-goes}

1. 메시지 상자에 원하는 일을 일등항해사에게 말해요.
2. 일등항해사가 요청을 작업으로 나누고, 각 작업을 선원에게 맡겨요.
3. 선원은 각자 프로젝트의 작업 사본에서 일하므로, 내 파일은 그대로 있어요.
4. 선원은 선장님의 결정이 필요하거나 일을 마치면 카드를 가져와요.
5. 카드에서 결정하면 선원들이 이어서 일해요.

결정할 일은 카드로 찾아와요.
선원들은 꼭 알아야 할 것만 가져오고, 결정은 선장님이 해요.

## 나만의 것 {#your-own}

Infinitary는 이미 가지고 있는 AI 구독으로 내 컴퓨터에서 실행돼요.

- **내 컴퓨터.**
  일등항해사, 선원들, 프로젝트가 모두 내 컴퓨터에 있어요.
  일은 내 프로젝트의 작업 사본에서 이루어져요.
- **내 구독.**
  Infinitary는 이미 가지고 있는 구독으로 일해요.
  크레딧도 사용량 과금도 없어요. 제공자의 청구서가 곧 모델 요금이에요.
- **내 기록.**
  모든 작업은 기록을 남겨요. 무엇을 요청했는지, 무엇이 바뀌었는지, 근거, 그리고 무엇을 결정했는지가 남아요.
