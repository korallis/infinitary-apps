Infinitary는 몇 시간마다 새 안정 버전이 있는지 확인해요.
확인할 때는 아무것도 내려받지 않고, 선장님이 고르기 전에는 아무것도 설치되지 않아요.
업데이트해도 저장된 작업은 그대로 남아요.

## 새 버전이 나오면 {#when-a-new-version-is-out}

창 오른쪽 위에 아래 화살표가 있는 둥근 버튼이 나타나요.
포인터를 올리면 "업데이트 가능"과 새 버전 번호가 보이고, 누르면 다음에 할 일을 볼 수 있어요.
설정 → **일반**의 **버전** 아래에도 같은 내용이 보여요.

직접 확인하려면 다음 중 하나를 쓰세요:

- 설정 → **일반**의 **버전** 아래에 있는 **업데이트 확인**.
- 명령 검색의 **업데이트 확인**.
- Mac에서는 Infinitary 메뉴의 **업데이트 확인…**.

다음에 할 일은 Infinitary를 설치한 방식에 따라 달라요.

## 다운로드 페이지에서 받은 Mac용 앱 {#a-mac-copy-from-the-downloads-page}

1. **업데이트 후 다시 시작**을 누르세요.
2. Infinitary가 새 버전을 내려받고 체크섬과 Apple 서명을 확인해요.
3. 선원들의 작업을 저장해요.
   실행 중인 작업은 실행하던 것을 먼저 마치므로 잃어버리는 것이 없어요.
4. Infinitary가 새 버전으로 다시 시작하고, 업데이트 때문에 멈췄던 작업을 이어 가요.

실행 중인 작업을 기다리는 동안 **나중에 업데이트**를 누르면, 다시 고를 때까지 업데이트를 미뤄요.
작업은 계속 진행돼요.

Infinitary가 다시 시작을 마치지 못했다면 버튼에 **다시 시작**이라고 적혀 있어요.
실행 중인 작업이 멈추면 다시 누르세요.

Infinitary는 응용 프로그램 폴더에서만 스스로 업데이트해요.
디스크 이미지에서 실행 중이라면 응용 프로그램으로 끌어다 놓고, 디스크 이미지를 꺼낸 다음 응용 프로그램에 있는 앱을 여세요.

## Homebrew로 설치한 Mac용 앱 {#a-mac-copy-from-homebrew}

Homebrew로 설치한 앱은 Homebrew로 업데이트해요.
안내에 명령과 함께 **명령 복사**가 보여요:

```sh wrap
brew update && brew upgrade --cask infinitary-labs/tap/infinitary
```

터미널에서 실행하세요.
Homebrew는 앱을 바꾸는 동안 Infinitary를 종료하므로, 끝나면 Infinitary를 다시 여세요.

## Linux {#linux}

- .deb나 .rpm 패키지로 설치한 **Ubuntu, Debian, Fedora**: **설치**를 누르세요.
  Infinitary가 새 버전을 내려받아 확인하고, 선원들의 작업을 저장하고, 암호를 물은 다음 다시 시작해요.
- **AppImage**: **설치**를 누르세요.
  Infinitary가 AppImage 파일을 새 버전으로 바꾸고 암호 없이 다시 시작해요.
  AppImage가 있는 폴더를 바꿀 수 있어야 해요.
- **Arch, Omarchy, NixOS**는 각자의 패키지 관리자로 업데이트해요.
  안내에 명령과 함께 **명령 복사**가 보여요. 터미널에서 실행하세요.

설치를 마치지 못하면 아무것도 바뀌지 않고 선원들의 작업은 계속 진행돼요.
그러면 안내에 같은 버전을 직접 설치하는 명령이 보여요.

## Windows {#windows}

1. **업데이트 후 다시 시작**을 누르세요.
2. Infinitary가 새 설치 프로그램을 내려받아 체크섬을 확인하고 선원들의 작업을 저장해요.
3. Infinitary가 닫히고 설치 프로그램이 교체한 뒤, 새 버전의 Infinitary가 다시 열려요.

설치를 끝낼 수 없으면 아무것도 바뀌지 않고 선원들의 작업은 계속돼요.

## 다른 컴퓨터와 휴대폰 {#your-other-computers-and-your-phone}

추가한 컴퓨터는 일등항해사가 있는 컴퓨터에서 업데이트를 받아요.
설정 → **기기**에서 다른 버전을 쓰는 컴퓨터의 줄에 **업데이트**가 보여요.
그 컴퓨터는 이 컴퓨터의 버전을 받고, 실행 중인 작업은 잠깐 멈췄다가 이어서 진행돼요.

일등항해사를 다루는 컴퓨터에서는 설정 → **일반**에 일등항해사가 있는 컴퓨터의 Infinitary 줄이 있어요.
그 컴퓨터에 업데이트가 준비되면, 그 이름이 붙은 **업데이트**를 눌러 지금 있는 곳에서 업데이트를 시작하세요.
휴대폰에서도 먼저 물어본 다음 그 업데이트를 시작할 수 있어요.
[다른 컴퓨터](/ko/your-other-computers/)와 [iPhone과 iPad](/ko/iphone-and-ipad/)를 보세요.

## Infinitary 제거하기 {#remove-infinitary}

앱을 제거해도 저장된 작업은 남아 있으므로, Infinitary를 다시 설치하면 두고 간 곳에서 이어 가요.
이 컴퓨터가 다른 컴퓨터의 작업을 실행하고 있다면, 먼저 설정 → **기기**에서 **나가기**를 누르세요.

- **다운로드 페이지에서 받은 Mac용 앱**: Infinitary를 종료하고 응용 프로그램에서 휴지통으로 옮기세요.
- **Homebrew로 설치한 Mac용 앱**: 터미널에서 `brew uninstall --cask infinitary`를 실행하세요.
  `--zap`은 절대 붙이지 마세요: 저장된 작업이 지워져요.
- **Linux**: 설치할 때 쓴 소프트웨어 설치 프로그램이나 패키지 관리자로 패키지를 제거하세요.
  AppImage라면 파일을 지우세요.
- **Windows**: Windows 설정 → **앱** → **설치된 앱**에서 Infinitary 메뉴의 **제거**를 고르세요.

저장된 작업은 Mac에서는 `~/Library/Application Support/infinitary`에, Linux에서는 `~/.config/infinitary`에, Windows에서는 `%APPDATA%\infinitary`에 남아 있어요.

### 저장된 작업을 지우는 것 {#what-deletes-your-saved-work}

다음은 그 폴더를 지우고, Infinitary가 그곳에 보관한 것도 함께 사라져요:

- `brew uninstall --zap`.
- 앱의 지원 파일까지 지우는 제거 앱.
- 폴더 자체를 휴지통으로 옮기거나 지우는 것.

다른 컴퓨터를 위해 일을 실행하는 컴퓨터에서는 그 폴더에 컴퓨터 자체의 키, 작업 사본, 작업의 파일이 들어 있어요.
그 폴더가 없으면 컴퓨터는 새 항목으로 다시 참여하고, 아직 가져오지 않은 작업은 잃어버린 채로 남아요.
[컴퓨터가 두 번 나열될 때](/ko/troubleshooting/#a-computer-is-listed-twice)를 보세요.
