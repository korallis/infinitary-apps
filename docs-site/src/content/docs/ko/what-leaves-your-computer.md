Infinitary는 이미 가지고 있는 구독으로 내 컴퓨터에서 실행돼요.
저희 계정이 필요 없고, 선장님의 작업은 저희를 거치지 않아요.
이 페이지는 앱이 무엇을 어디로 보내는지 정리해요.

## 작업은 고른 제공자에게 가요 {#your-work-goes-to-the-provider-you-chose}

일등항해사와 선원들은 로그인한 AI 구독으로 생각해요.
선장님의 메시지와, 선원이 작업을 하려고 읽는 프로젝트 내용은 구독을 통해 그 제공자에게 가요.
Claude를 쓰면 Infinitary는 설치된 Claude Code를 사용하고, 그 Claude Code는 선장님의 계정으로 로그인되어 있어요.
사용자 지정 제공자를 쓰면 입력한 주소로 가요.

로그인 정보는 컴퓨터에 남아 있어요.

## 프로젝트는 프로젝트가 있는 곳으로 가요 {#your-projects-go-where-they-live}

선원은 컴퓨터에 있는 프로젝트의 작업 사본에서 일해요.
작업을 끌어오기 요청으로 올릴 때는 그 분기를 GitHub, GitLab, Bitbucket 같은 프로젝트가 있는 곳에 푸시하고, 그곳에서 끌어오기 요청을 열어요.
이 컴퓨터에만 있는 프로젝트는 이 컴퓨터에만 남아요.

선원은 작업 사본을 준비하거나 작업을 할 때, 선장님이 직접 하듯이 프로젝트에 필요한 것을 가져올 수 있어요.

## 다른 컴퓨터와 휴대폰 {#your-other-computers-and-your-phone}

추가한 컴퓨터와 휴대폰은 일등항해사가 있는 컴퓨터와 이야기해요.
설정 → **기기**에서 그 컴퓨터를 어떻게 찾는지 알려 줘요.
**인터넷으로**에는 "안 해요. Infinitary는 이 컴퓨터를 인터넷에 열지 않아요."라고 적혀 있어요.

다른 컴퓨터를 위해 입력한 로그인 정보는 그 컴퓨터로 한 번 가요.
일등항해사가 있는 컴퓨터는 사본을 남기지 않아요.
[다른 컴퓨터](/ko/your-other-computers/)를 보세요.

## 연결한 연동 {#integrations-you-connect}

설정 → **연동**에서 연결한 Google 같은 연동은 자체 로그인으로 닿고, 그 로그인은 로그인한 컴퓨터에 남아요.
일등항해사와 선원들은 연결한 뒤에만 그것을 읽어요.
[연동](/ko/integrations/)을 보세요.

## 회사의 사용량 보고 {#your-companys-usage-reporting}

Claude Code 설정 파일이나 셸에서 Claude Code 안내서대로 회사용 사용량 보고를 설정해 두었다면, Infinitary는 여기서 한 모든 작업의 사용량을 같은 곳으로 보내요.
Claude의 작업은 Claude Code가 직접 그곳에 보낼 기록 그대로 가요.
다른 모델의 작업은 같은 이름으로, 모델, 제공자, 토큰, 예상 비용, 일등항해사와 크루원 중 누가 했는지, 작업 종류, Claude Code 로그인 이메일과 함께 가요.
내가 쓴 말, 작업 제목, 프로젝트 이름은 보내지 않아요.
설정 → **사용량**에서 어디로 가는지 알려 줘요.
그곳에서 Claude의 작업을 계속 거부하거나 그곳에 닿지 않으면, 그 줄이 대신 그 사실을 알려 줘요.
회사 관리자가 컴퓨터 전체에 관리하는 설정은 지금처럼 Claude Code에 바로 닿고, Infinitary는 다른 모델의 작업도 같은 방식으로 그곳에 보내요.
어느 쪽 설정이든 사용량을 gRPC로 보내면 Claude의 작업만 가고, 그때는 설정 → **사용량**에서도 그렇게 알려 줘요.

## 업데이트 확인 {#update-checks}

Infinitary는 몇 시간마다 릴리스가 게시되는 곳에서 새 버전이 있는지 확인해요.
이 확인은 선장님의 내용도, ID도 보내지 않아요.
하루의 첫 확인과 한 달의 첫 확인은 첫 확인이라는 것도 알려서, Infinitary Labs가 Infinitary를 쓰는 컴퓨터 수를 셀 수 있게 해요.
이것은 **진단** 스위치와 상관없이 일어나며, Homebrew로 설치한 앱은 보내지 않아요.
새 버전은 업데이트하기로 고를 때만 내려받아요.
**업데이트 확인**을 직접 누를 수도 있어요.
[Infinitary 업데이트와 제거](/ko/update-and-remove/)를 보세요.

## 받아쓰기 {#dictation}

받아쓰기는 컴퓨터 안에서 목소리를 글로 바꿔요.
처음 쓸 때 음성 모델을 한 번 내려받기 전에 물어봐요.

## 진단, 저희에게 보내는 단 하나의 스위치 {#diagnostics-the-one-switch-that-sends-to-us}

설정 → **일반** → **공유**에 **진단** 스위치가 있어요.
저희에게 무언가를 보내는 스위치는 이것 하나뿐이에요. 이 스위치 없이 저희에게 닿는 것은 위에서 말한 업데이트 확인의 하루 첫 확인과 한 달 첫 확인 표시뿐이고, **공유**에서도 이를 설명해요.
끄지 않는 한 켜져 있고, 앱의 어떤 기능도 이 스위치에 기대지 않아요.

처음 실행할 때 메시지 상자 아래의 안내가 무엇을 보내는지 알려 주고, **끄기**와 **확인**이 있어요.
답하기 전에는 아무것도 보내지 않아요.

진단은 익명 사용 이벤트를 보내요:

- 앱이 열림,
- 일등항해사가 차례를 마치거나 실패함, 실패의 종류만 포함,
- 처음 설정이 어디까지 진행됐는지,
- 그리고 추가한 iPhone이나 iPad에서는 앱이 열림, 설정됨, 메시지를 보냄, 카드에 답함.

각 이벤트에는 앱 버전과 무작위 설치 ID가 붙어요.
이 ID는 선장님이나 컴퓨터에 대한 어떤 것과도 연결되지 않고, 진단을 껐다가 다시 켤 때마다 바뀌어요.
선장님이 쓴 텍스트, 이름, 경로는 보내지 않아요: 대화, 코드, 카드는 절대 보내지 않아요.
휴대폰은 스스로 아무것도 보내지 않아요. 컴퓨터가 같은 스위치 아래에서 휴대폰의 이벤트를 보내요.

무엇이 나갈지 정확히 보려면 **공유** 아래의 **이 컴퓨터에서 나가게 될 내용**을 여세요.
설치 ID, 보내기를 기다리는 것, 보낸 것, 그리고 진단이 보낼 수 있는 모든 이벤트를 보여 줘요.
**진단**을 끄면 더 이상 아무것도 기록하거나 보내지 않아요.

## 비밀 정보 {#secrets}

설정 → **비밀 정보**에 보관한 값은 컴퓨터에 남아요.
각 값은 곧장 비밀 정보로 들어가요: Infinitary는 그 값을 다시 보여 주지 않고, 일등항해사도 선원들도 받지 않아요.
[비밀 정보](/ko/secrets/)를 보세요.
