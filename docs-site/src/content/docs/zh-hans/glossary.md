这些是 Infinitary 中带有特定含义的词，按英文字母顺序排列。
每个词都链接到完整解释它的页面。

## A {#a}

### 动态（Activity） {#activity}

窗口左侧底部的面板，你的大副和船员所做的每件事在其中各占一行。
某个任务自己的各行在它卡片的“**动态**”标签上。
请参阅[面板](/zh-hans/panels/#the-apps-own-panels)。

### 额度（Allowance） {#allowance}

你的 AI 套餐在重置前还剩多少，例如一个会话或一周的额度。
设置 → **智能** 会把它显示为每个账户上的一条计量条。
请参阅[订阅和额度](/zh-hans/subscriptions-and-quota/#read-your-plans-allowance)。

### 合并前先询问（Ask before merging） {#ask-before-merging}

项目的一个开关，决定由谁来合并它已完成的工作。
开启时，工作会等你点击它的合并卡片；关闭时，通过检查的工作可能不经询问你就合并。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/#asking-before-merging)。

### 自动化（Automation） {#automation}

大副按计划收到的提示，或每当发生某件事（例如一个任务结束）时收到的提示。
请参阅[自动化](/zh-hans/automation/)。

## B {#b}

### 待办列表（Backlog） {#backlog}

任务在你对它点击“**开始**”之前所在的位置。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/#where-a-task-stands)。

### 这批改动（Batch） {#batch}

对于改动以 **批量拉取请求** 方式提交的项目，指把你已批准的改动合在一起的一个拉取请求，每个改动一个提交，并在检查通过后合并。
等待所属这批改动的改动会在“任务”中显示“批量”。
请参阅[项目](/zh-hans/projects/#how-changes-reach-your-project)。

### 分支（Branch） {#branch}

项目中用 git 保存的一条独立的改动线。
每名船员都在自己的分支上做改动，合并则把它们带入你的项目。
请参阅[项目](/zh-hans/projects/#working-copies)。

## C {#c}

### 卡片（Card） {#card}

你的大副或一名船员把一个回答、一项发现或一个决定连同背后的证据交给你的方式。
卡片会一张一张地出现在窗口中央，每张都是一张[便笺](#note)或一个[决定](#decision)。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/)。

### 检查（Checks） {#checks}

你的项目在一项改动合并前对它运行的测试和其他检查。
“**检查通过后合并**”会等待它们，检查未通过时由一名船员来修复。
请参阅[你的第一个任务](/zh-hans/your-first-task/#5-merge-it)。

### 命令搜索（Command search） {#command-search}

一个搜索框，可以找到 Infinitary 中的任何命令并显示它的按键。
在 Mac 上按 ⌘K，在 Linux 和 Windows 上按 Ctrl+K。
请参阅[键盘](/zh-hans/keyboard/#command-search)。

### 运行工作的电脑（Computer that runs work） {#computer-that-runs-work}

你添加的另一台电脑，它负责做你的项目的工作，那里不需要打开任何窗口，并使用它自己的订阅。
设置 → **项目** 中的“**运行于**”为每个项目选择电脑。
请参阅[你的其他电脑](/zh-hans/your-other-computers/#a-computer-that-runs-work)。

### 大副所在的电脑（Computer where your first mate lives） {#computer-where-your-first-mate-lives}

保存你的大副及其任务、卡片和对话的那一台电脑。
你的其他电脑和你的手机都到那里找你的大副，因此它需要保持唤醒并打开 Infinitary。
请参阅[你的其他电脑](/zh-hans/your-other-computers/#the-computer-where-your-first-mate-lives)。

### 控制中（Controlling） {#controlling}

你添加的另一台电脑在那里打开 Infinitary 时所做的事：它显示大副所在电脑上的大副。
它窗口顶部会显示“控制大副：”和那台电脑的名称。
请参阅[你的其他电脑](/zh-hans/your-other-computers/#control-your-first-mate-from-another-computer)。

### 大副的副本（Copy of your first mate） {#copy-of-your-first-mate}

由一台运行工作的电脑保存的、你的大副记录的实时副本，使那台电脑可以[接手](#take-over)。
请参阅[你的其他电脑](/zh-hans/your-other-computers/#keep-a-copy-on-another-computer)。

### 船员的浏览器（Crew's browser） {#crews-browser}

船员为自己的任务使用的浏览器，与你自己的浏览器及其登录状态相互隔离。
你可以观看并接管它，而购买或预订始终由你来完成。
请参阅[船员的浏览器](/zh-hans/the-crews-browser/)。

### 船员（Crewmate） {#crewmate}

在你的项目的独立工作副本中完成一个任务的 AI 帮手。
你的船员是你所有船员合起来的统称，由你的大副统领。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/)。

## D {#d}

### 决定（Decision） {#decision}

一张请你做出选择的卡片。
它提供两三个选项，作者推荐的那个是主按钮。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/#notes-and-decisions)。

### 诊断（Diagnostics） {#diagnostics}

唯一会向我们发送内容的开关：匿名的使用事件，不含你写的文字、名称和路径。
它在设置 → **通用** 的“**共享**”下。
请参阅[哪些内容会离开你的电脑](/zh-hans/what-leaves-your-computer/#diagnostics-the-one-switch-that-sends-to-us)。

## F {#f}

### 大副（First mate） {#first-mate}

你在 Infinitary 中与之交谈的那一位，显示在窗口中央。
它回答你的问题，把工作变成任务，为每个任务安排一名船员，并给你送来卡片，而它自己从不编辑你的文件。
请参阅[大副](/zh-hans/the-first-mate/)。

### 聚焦（Focus） {#focus}

通过顶部栏的项目标签，把窗口收窄到一个项目。
“任务”、“动态”和卡片随后只显示这个项目，你提出的新工作也会放在这里，除非你指明另一个项目。
请参阅[项目](/zh-hans/projects/#focus-on-one-project)。

## I {#i}

### 集成（Integration） {#integration}

与你的项目之外某样东西的连接，例如 GitHub、Gmail 或一个 MCP 服务器，以你的身份登录。
你的大副、你的船员、你的自动化和你的面板都以同样的方式使用它。
请参阅[集成](/zh-hans/integrations/)。

## K {#k}

### 知识（Knowledge） {#knowledge}

你的大副和你的船员为以后的工作保存的内容：长期指引、个人背景和保存的来源。
请参阅[知识](/zh-hans/knowledge/)。

## M {#m}

### 合并（Merge） {#merge}

把一项已完成的改动带入你的项目。
你在改动的合并卡片上合并它，而不要求合并前先询问的项目可能不经询问你就合并它。
请参阅[你的第一个任务](/zh-hans/your-first-task/#5-merge-it)。

### 合并卡片（Merge card） {#merge-card}

改动准备好时船员送来的卡片。
它讲述这项改动的改动说明，配有“之前”和“之后”的图片以及风险图示，它的按钮会合并或丢弃这项工作。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/#merge-cards)。

### 消息框（Message box） {#message-box}

窗口底部的框，你在这里向大副输入文字，或用说话代替打字。
在任何地方按 ⌘L（Linux 和 Windows 上按 Ctrl+L）都能跳到它。
请参阅[大副](/zh-hans/the-first-mate/#talking-to-your-first-mate)。

## N {#n}

### 便笺（Note） {#note}

告诉你一件事、不问你任何问题的卡片。
它唯一的按钮是“**知道了**”；如果读完它就会结束它所回答的任务，按钮则是“**完成**”。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/#notes-and-decisions)。

## O {#o}

### 无法联系（Out of reach） {#out-of-reach}

用来说 Infinitary 此刻联系不上的电脑或手机，例如处于睡眠状态的、Infinitary 已关闭的，或在另一个网络上的。
需要它的工作会等到它恢复。
请参阅[故障排查](/zh-hans/troubleshooting/#another-computer-is-out-of-reach)。

## P {#p}

### 面板（Panel） {#panel}

窗口侧边的一个框，例如“动态”、“任务”，或你的大副为你构建的面板。
请参阅[面板](/zh-hans/panels/)。

### 个人背景（Personal context） {#personal-context}

你告诉大副的关于你自己的事，例如“我刚开始学编程”，保存下来以便以后的工作使用。
请参阅[知识](/zh-hans/knowledge/#tell-your-first-mate-about-yourself)。

### 计划（Plan） {#plan}

船员在构建较大的东西之前送来的卡片，只询问应由你来做的决定。
“**批准并构建**”会开始这项工作，“**保存并推迟**”会把计划留到以后。
请参阅[你可以请求什么](/zh-hans/what-you-can-ask-for/#a-plan-before-building)。

### 私有站点（Private sites） {#private-sites}

你列出的、位于办公室、家庭或 VPN 网络中的站点，任务的浏览器可以打开它们。
你的大副从不自己添加站点：它会在卡片上询问你。
请参阅[船员的浏览器](/zh-hans/the-crews-browser/#private-sites)。

### 项目（Project） {#project}

你自己的一个用 git 保存的文件夹，由你的船员在其中工作。
每个任务都属于一个项目。
请参阅[项目](/zh-hans/projects/)。

### 拉取请求（Pull request） {#pull-request}

在你的项目托管处（例如 GitHub 或 GitLab）提出的、请求合并的改动，它的检查在那里运行。
在它的合并卡片上，“**合并拉取请求**”会合并它。
请参阅[项目](/zh-hans/projects/#how-changes-reach-your-project)。

### 放到一边（Put aside） {#put-aside}

不回答而把一张卡片隐藏起来。
它会在“任务”中的“**等你处理**”下等候，作者修改它时就会回来。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/#putting-a-card-aside)。

## Q {#q}

### 排队中（Queued） {#queued}

任务所在的位置：等它所等待的事情（例如另一个任务）完成后自行开始。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/#where-a-task-stands)。

## R {#r}

### 记录（Record） {#record}

每个任务都会保留的内容：你要求了什么、改动了什么、证据，以及你的决定。
任务的记录在任务结束后仍会保留。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/)。

### 把关（Rigor） {#rigor}

工作在送到你面前之前被检查得有多彻底：“**快速**”、“**默认**”或“**谨慎**”。
每个项目都有自己的设置，在设置 → **项目** 中。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/#rigor)。

### 操作手册（Runbook） {#runbook}

你的大副和你的船员在做某类工作时遵循的书面指南，例如规划一项改动或教一堂课。
它不会在你的电脑上运行任何东西。
请参阅[操作手册](/zh-hans/runbooks/)。

## S {#s}

### 机密（Secret） {#secret}

你的船员按名称使用的密码或密钥，且只有在你允许这次使用之后才能用。
Infinitary 不会再次显示它的值，你的大副和你的船员也都拿不到它。
请参阅[机密](/zh-hans/secrets/)。

### 已登录的网站（Signed-in sites） {#signed-in-sites}

你在某个任务的浏览器中登录过的站点，保存在那台电脑的浏览器配置文件中。
对每一个站点，你可以选择以后的任务是先询问你，还是不经询问就使用它。
请参阅[船员的浏览器](/zh-hans/the-crews-browser/#signed-in-sites)。

### 长期指引（Standing direction） {#standing-direction}

用你自己的话说明从现在起你希望工作怎样进行，由你的大副保存并遵循。
它适用于所有地方，或只适用于一个项目。
请参阅[知识](/zh-hans/knowledge/#give-a-standing-direction)。

### 订阅（Subscription） {#subscription}

你已有的 AI 套餐，例如 Codex 或 Claude，你的大副和你的船员通过它工作。
你登录的每一个订阅，都是设置 → **智能** 中的一个账户。
请参阅[订阅和额度](/zh-hans/subscriptions-and-quota/)。

## T {#t}

### 接手（Take over） {#take-over}

在大副所在的电脑无法联系时，在保存着它副本的电脑上启动你的大副。
只有你的点击才会启动它。
请参阅[你的其他电脑](/zh-hans/your-other-computers/#take-over)。

### 任务（Task） {#task}

大副跟踪的一项工作，带有一个类似 `WEB-12` 的编号，编号以它所属项目的任务编号前缀开头。
窗口右侧的“任务”按任务所处的状态把它们列出来。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/)。

### 任务看板（Task board） {#task-board}

你的任务的更完整视图：顶部是“**等你处理**”，然后是“待办列表”、“排队中”和“工作中”几列。
点击“任务”标题栏中的“**打开任务看板**”。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/#the-task-board)。

### 讨论（Thread） {#thread}

你的第一次回复在卡片旁边打开的对话。
卡片的作者会在那里回答你。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/#the-reply-field-and-the-thread)。

## W {#w}

### 等你处理（Waiting on you） {#waiting-on-you}

“任务”中列出有卡片需要你做决定的任务的位置。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/#where-a-task-stands)。

### 工作副本（Working copy） {#working-copy}

船员在自己的分支上工作所用的你的项目的副本，因此在你合并之前，你自己的文件保持原样。
请参阅[项目](/zh-hans/projects/#working-copies)。
