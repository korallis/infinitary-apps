Infinitary 是你自己的 AI 工作室。
它是一款适用于 macOS、Linux 和 Windows 的桌面应用。
你只与一位大副交谈，由一队 AI 船员完成工作。

## 一个任务怎样进行 {#how-a-task-goes}

1. 你在消息框里告诉大副你想要什么。
2. 大副把你的要求拆分成任务，并把每个任务交给一位船员。
3. 每位船员都在你的项目的独立工作副本中工作，所以你的文件原地不动。
4. 当船员需要你做决定，或已经完成时，它会给你带来一张卡片。
5. 你在卡片上做出决定，船员们继续工作。

决定以卡片的形式来到你面前。
船员们只带回你需要知道的内容，由你来做决定。

## 属于你自己 {#your-own}

Infinitary 在你的电脑上运行，使用你已有的 AI 订阅。

- **你的电脑。**
  大副、船员们和你的项目都在你的电脑上。
  工作在你自己项目的工作副本中进行。
- **你的订阅。**
  Infinitary 通过你已有的订阅工作。
  没有点数，也不计量：服务商的账单就是你的模型账单。
- **你的记录。**
  每个任务都会留下一份记录：你要求了什么、改动了什么、证据，以及你的决定。
