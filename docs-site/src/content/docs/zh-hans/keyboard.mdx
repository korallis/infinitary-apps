Infinitary 中的一切都能用键盘完成。
Tab 在控件之间移动，方向键在列表内移动。

## 命令搜索 {#command-search}

在 Mac 上按 <kbd>⌘K</kbd>，在 Linux 和 Windows 上按 <kbd>Ctrl+K</kbd>，打开命令搜索。
输入几个词，用方向键选择一个命令，然后按 Enter。
本页的每个命令都在那里，旁边是它的按键，没有按键的命令也在其中。

## 预设 {#presets}

Infinitary 自带几套按键，称为预设：Vim、Emacs、VS Code、Tmux、Legacy。
新安装的 Infinitary 从 Vim 开始。
只有在预设出现之前就用过 Infinitary 的人才会看到 Legacy。
在**设置**的**键盘**下选择一套预设。

## 更改按键 {#change-a-key}

在**设置**的**键盘**下，每个命令都有**录制**、**移除**和**重置**。
点击**录制**，按下你想要的按键，然后按 Enter 保存。
如果另一个命令已经在用这些按键，Infinitary 会在做出任何更改之前告诉你是哪一个。
