面板是 Infinitary 窗口侧边的一个方框。
面板位于两条侧栏上，一条在左，一条在右，围绕着你与大副的对话。
没有内容可显示的侧栏不占空间。

每个面板都有一个带标题的页眉。
点击页眉的箭头即可折叠面板，或再次展开。
折叠的面板仍然可以用几个字说明它里面有什么，例如有多少个任务在等你。

## 应用自带的面板 {#the-apps-own-panels}

Infinitary 自带这些面板。

- **动态**，位于左侧栏底部。
  它逐行显示大副和船员正在做什么。
- **任务**，位于右侧栏底部。
  它列出你的任务，并显示哪些在等你。
  它的“**搜索任务**”按钮可以查找任务，“**打开任务看板**”会打开整个看板。
- **知识**，位于“任务”下方。
  它显示大副保存的长期指引，“**打开知识**”会打开船员学到的其余内容。
  有知识可显示后，它才会出现。
  请参阅[知识](/zh-hans/knowledge/)。
- **自动化**，位于“知识”下方。
  它列出你的自动化，以及每一项下次何时运行。
  保存了自动化后，它才会出现。
  请参阅[自动化](/zh-hans/automation/)。

## 排列你的面板 {#arrange-your-panels}

你可以把任何面板移到任一侧栏的其他位置。

- **在侧栏上。**
  按住面板的页眉并拖动。
  一条线会显示它将落在哪里。
  在那里松手即可移动它，在其他任何地方松手则会放回原处。
- **在设置中。**
  打开“**设置**”，再打开“**面板**”。
  列表按顺序显示每条侧栏的顶部和底部分组。
  拖动一行即可移动它的面板，或用它的开关隐藏或显示面板。
  “**恢复默认**”会把每个面板放回它最初的位置。
- **通过询问。**
  告诉大副你想把面板放在哪里，例如“把任务移到左侧栏”。

你隐藏的面板仍留在“**设置**”的列表中，因此你可以再次显示它。
当侧栏空间不够时，最靠近中间的面板会先折叠。
如果连它们的页眉也放不下，会有一行（例如“**还有 2 个**”）列出其余的面板。
在那里选择一个，就能把它带回侧栏。

## 使用键盘 {#use-the-keyboard}

- 按 F6 移到窗口的下一个部分，面板也包括在内。
  Shift+F6 则向后移动。
- 按 ⌘, （Linux 和 Windows 上按 Ctrl+,）打开“**设置**”。

有些面板会添加自己的命令，例如“**查找任务**”和“**打开知识**”。
你可以在命令搜索中找到它们，也可以在“**设置**”的“**键盘**”中为它们指定按键。
请参阅[键盘](/zh-hans/keyboard/)。

## 大副为你制作的面板 {#panels-your-first-mate-builds-for-you}

你可以要求制作一个属于你自己的面板。
告诉大副它应该显示什么，例如“给我做一个显示东京天气的面板”。
一名船员会用应用自己的组件来制作它，所以它看起来和 Infinitary 的其余部分一样。

在你的船员完成三个任务后，左侧栏顶部会出现一个空的“**创建你自己的面板**”框。
点击它，即可在消息框中开始提出要求。
点击它的“**隐藏**”可以永久收起它。

除非你说明位置，否则你要求的面板会落在左侧栏顶部。
它的页眉会写着“**你的**”。
你可以像移动其他面板一样移动它。
要修改它，请告诉大副你想要哪些不同。
要删掉它，请让大副移除它。

## 关闭你的面板 {#turn-your-panels-off}

“**设置**”中的“**通用**”→“**你的面板**”可以一次关闭大副为你制作的所有面板。
应用自带的面板会保留。
重新打开这个开关，你的面板就会回来。

如果 Infinitary 在刚启动后连续两次关闭，它会自动关闭你的面板，以防其中某一个是原因。
这时开关会说明这一点。
准备好后，再把它们重新打开。

如果你的某个面板停止工作，面板会这样告诉你，窗口的其余部分则继续运行。
当某个面板的后台工作停止响应时，它的“**重试**”按钮会让它重新启动。
