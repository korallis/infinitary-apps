机密用来保存船员工作时需要的密码和密钥，例如发布你网站的那个密钥。
船员按名称使用机密，而且只有在你允许那一次使用之后才能用。
每个值都直接存入你电脑上的机密：Infinitary 不会再显示它，大副和船员也都拿不到它。

## 你的机密存放在哪里 {#where-your-secrets-live}

打开**设置**，再打开**机密**，或者在命令搜索中搜索**打开机密**。

**受保护的机密**按名称和位置列出每个机密，并显示最近使用它的任务以及使用时间。
**搜索机密**可以按名称、位置或最近使用它的任务查找机密。

在 Mac 上，列表下方的一行写着“保存在这台电脑上。你的船员会使用它们，但永远看不到。”
在 Linux 和 Windows 上，这一行说明船员只有经你批准才会使用它们，但在系统的机密存储解锁期间，你运行的任何程序都能访问它们。

机密留在大副所在的那台电脑上。
从别处控制你大副的电脑没有自己的机密部分。

## 保存一个机密 {#keep-a-secret}

1. 选择**添加机密**。
2. 给它起一个**名称**，例如“网站部署”。
3. 把值粘贴到**机密值**中。
4. 如果你有两个同名的机密，用**位置（可选）**区分它们，例如 staging 或 production。
5. 选择**保存机密**。

保存后值会一直隐藏，只有你允许的使用才能拿到它。
打开某个机密所在的行，可以**替换**它的值或**忘记**它。
忘记会把它从这台电脑上移除，但不会在创建它的地方停用这个密钥。

### 当船员需要一个你还没保存的机密时 {#when-a-crewmate-needs-one-you-have-not-kept}

船员需要一个你还没保存的机密时，会按名称请求它，绝不会索要它的值。
随后 Infinitary 会显示自己的卡片，例如“将‘网站部署’添加到机密？”，并附上船员用自己的话写的理由。
当你需要自己创建或找到这个机密时，卡片还会显示**获取方法**：船员为这种情况列出的步骤、名称或位置，以及一行说明是谁写的。
在那里登录之前，请核对它显示的每个地址。

在 Infinitary 于卡片上绘制的隐藏字段中输入或粘贴每个值，然后选择**保存机密**。
**不保存**则什么都不保存。
船员拿到的是机密的名称，绝不是它的值，而且每次使用仍会询问你。

只在 Infinitary 绘制的字段中输入机密，绝不要输入到卡片的回复字段或你的消息框中。

## 允许一次使用 {#allow-a-use}

船员想使用某个机密时，Infinitary 会显示一张卡片，例如“要把‘网站部署’机密交给‘发布网站’吗？”。
卡片会准确说明谁会拿到它：

- **机密**：每个机密，以及程序拿到它时使用的名称。
- **运行**：确切的命令。
- **所在文件夹**：它在哪里运行。
- **理由**：船员用自己的话说明的理由。

**检查过的全部内容**列出 Infinitary 对这个程序检查了什么，以及哪些无法检查。
然后选择：

- **允许一次**只把机密交给这一次运行。
- **始终允许**把机密交给这一次运行，并保存这次确切的运行：同样的程序、文件、参数和文件夹。
  有任何不同都会再次询问。
- **不允许**表示拒绝，下一次运行会再次询问。

每次允许前都会先请你确认：在 Mac 上用触控 ID 或密码，在 Linux 上用密码，在 Windows 上用 Windows Hello 或 Windows 密码。
拿到机密的程序可以保留它。
允许绝不代表批准另一个单独的操作，例如部署或发送某些内容。
船员只会得知这次运行是否完成，而不会知道它输出了什么。

请求等待期间，设置 → 机密会把它显示在顶部，并提供**查看请求**来打开它的卡片。

## 已保存的决定 {#saved-decisions}

打开机密列表下方的**访问、历史记录与恢复**，再打开**已保存的决定**。
你用**始终允许**保存的每个决定都会以一句话列出。

决定只能在请求的卡片上保存。
在这里你可以**移除**某个决定：你的电脑会请你确认，船员下次使用前会再次询问你。

## 在手机上批准 {#approve-from-your-phone}

不在电脑旁时，你可以在 iPhone 或 iPad 上允许一次使用。

1. 在设置 → **设备**中，打开你手机所在行的**批准机密使用**。
2. 在手机上打开 Infinitary，它随后会显示自己的代码。
3. 选择**比对代码**，确认电脑卡片上的代码与手机设置中的代码一致。
4. 在电脑上选择**确认并允许**，电脑会请你确认。

此后，手机上请求的卡片会提供**允许一次**和**不允许**。
每次允许都需要面容 ID、触控 ID 或手机密码。
始终允许某次运行的决定只保存在你的电脑上。
从别处控制你大副的 Mac 也可以批准使用，在它自己的那一行用同样的方式设置。

要停止，请关闭这个开关，或者在**访问、历史记录与恢复**中的**批准设备**下选择**停止批准**。

## 从其他工具迁入机密 {#move-secrets-from-another-tool}

如果你把机密保存在其他工具中，例如 Automic Vault、.env 文件或 Mac 的钥匙串，船员可以把它们迁入机密，而不会看到任何值。

1. 在设置 → 机密中选择**从其他工具迁入**，或在命令搜索中选择**从其他工具迁入机密**。
2. 你的消息框会开始向大副发出请求；写上工具的名称并发送。
3. 船员会显示一张卡片，例如“要从 Automic Vault 导入 3 个机密吗？”，写明它要运行的命令或要读取的文件，以及原因。
4. 勾选每个要保存的机密，然后选择**导入机密**，或选择**不导入**。

Infinitary 会自己运行命令或读取文件，并且只保存你勾选的内容。
对于 .env 文件这样的文件，**读取**会先列出其中包含的名称。
船员拿到的是名称，绝不是值，其他工具里的副本也保持原样。
你要在大副所在电脑上的 Infinitary 窗口中挑选机密，而不是在手机上。

## 集成的密钥 {#keys-for-your-integrations}

当你在设置 → **集成**中登录 Google，或添加带密钥的 MCP 服务器时，Infinitary 会把这些密钥保存在机密中。
机密列出它们时，用**在集成中管理**代替替换和忘记。
Infinitary 使用它们时不会询问，因为登录或添加带密钥的服务器本身就是你的同意。
船员看不到它们，也不能请求使用它们。
要忘记它们，请在集成中退出登录或移除服务器。
参见[集成](/zh-hans/integrations/)。

## 使用历史记录和备份 {#use-history-and-backups}

**使用历史记录**列出每一次使用：用了哪些机密、理由、程序、以何种方式被允许以及结果如何，绝不包含值。
它会一直保留，直到你删除它，并提供**导出历史记录**和**删除历史记录**。

**备份与恢复**中有**保存加密备份**，它会保存一份加密副本和一个单独的恢复密钥。
请将它们分开保管：同时拥有两者的人都能读取已保存的值，而且密钥无法重置。
**从备份恢复**会替换你已存储的值，并清除已保存的决定、手机批准和临时访问权限。

## 当机密无法打开时 {#when-secrets-cannot-open}

如果电脑的机密存储已锁定，机密会显示**存储已锁定**，并提供**解锁或重新检查**。
请求会一直等待，直到它打开。

如果 Infinitary 再也无法读取它保存的内容，机密会显示**需要恢复**，并且不允许任何使用。
**恢复选项**会打开**备份与恢复**，以便从备份恢复。
**重新开始**会清除你已存储的机密、已保存的决定、手机批准和临时访问权限，而且无法撤销。

## 已登录的网站 {#signed-in-sites}

机密底部列出**已登录的网站**：你在任务浏览器中登录过的网站。
它们保存在那台电脑的浏览器配置文件中，而不是受保护的存储中。
参见[船员的浏览器](/zh-hans/the-crews-browser/#signed-in-sites)。

## 当你的大副迁移时 {#when-your-first-mate-moves}

当你的大副迁移到另一台电脑时，你的机密会留在它离开的那台电脑上，你需要在新电脑上重新添加。

[保留大副副本](/zh-hans/your-other-computers/#keep-a-copy-on-another-computer)的电脑也可以保存你的机密。
在设置 → **设备**中，从这台电脑的**接手准备**列表里选择**在那里保留机密**，然后在那台电脑上亲自确认。
如果你的大副之后迁移到那里，或[从那份副本启动](/zh-hans/your-other-computers/#take-over)，它会把这些值一起带过去。
如果那台电脑已经保存了自己的机密，那里会有一张卡片询问使用哪一组。
它不会带来已保存的决定和批准设备，所以每次使用都会再次询问你，每部手机也要重新设置。

另请参见[你的其他电脑](/zh-hans/your-other-computers/#move-your-first-mate)和[哪些内容会离开你的电脑](/zh-hans/what-leaves-your-computer/#secrets)。
