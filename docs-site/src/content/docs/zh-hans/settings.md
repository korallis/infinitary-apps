用 ⌘, （Linux 和 Windows 上用 Ctrl+,）、窗口顶部的“**设置**”按钮，或命令搜索中的“**打开设置**”来打开设置。
各个分区列在左侧。
上下方向键可以在它们之间移动，按 Escape 或点击“**返回**”即可离开设置。

你也可以让大副替你更改某项设置，例如“切换到浅色主题”或“打开环境音乐”。

## 通用 {#general}

- “**登录时启动**”会在你登录电脑时打开 Infinitary。
- 在 Mac 上，“**在程序坞中显示**”关闭时会隐藏程序坞图标，窗口仍会保留。
- “**大副需要我时通知我**”会在窗口处于后台时，为决定和汇报发送一条安静的通知。
- “**听写**”让你按一下或按住一个键来说话，而不是打字，说的话会在你的电脑上转成文字。
  关闭后，这个键和麦克风就留给其他应用。
  请参阅[大副](/zh-hans/the-first-mate/#talk-instead-of-typing)。
- “**你的面板**”会收起大副为你制作的每个面板，以及你添加的面板，直到你重新打开它。
- “**清除任务数据**”会移除每个任务及其工作副本、笔记和卡片，以及船员记录的知识。
  点击“**清除**”，再点击“**确认清除**”。
- “**共享**”中有“**诊断**”开关、一行说明无论该开关如何设置检查更新都会告诉我们什么的文字，以及“**哪些内容会离开这台电脑**”。
  请参阅[哪些内容会离开你的电脑](/zh-hans/what-leaves-your-computer/#diagnostics-the-one-switch-that-sends-to-us)。
- “**版本**”会写出你运行的版本，并可再次打开你看过的每一条发布说明。
  在它下面，Infinitary 会说明你是否已是最新版本，并带有一个按钮，例如“**检查更新**”。
  请参阅[更新和移除 Infinitary](/zh-hans/update-and-remove/)。

在从别处控制大副的电脑上，“通用”还会列出“**网站登录**”：你在那里[任务的浏览器](/zh-hans/the-crews-browser/#signed-in-sites)中登录过的网站。
在大副所在的电脑上，它们位于“**机密**”下的“**已登录的网站**”中。

## 外观 {#appearance}

- “**大小**”会把文字及其周围的一切放大，可选 100%、110%、125% 或 150%。
- “**默认卡片大小**”选择卡片打开时的大小：“**常规**”“**宽**”“**全宽**”或“**最大化**”。
  你仍可以单独调整每张卡片的大小。
- “**保持卡片最大化**”会在你最大化一张卡片后，让每张卡片都保持最大化，直到你还原其中一张。
- “**主题**”是“**深色**”或“**浅色**”。
- 在 Mac 上，“**窗口底色**”设置主题颜色覆盖模糊背景的程度。
  默认为 0%。
- “**船员模型名称**”会在你的船员只使用一个轨道时显示模型名称。

### 字体 {#fonts}

Infinitary 有三种可供你选择的字体：

- **应用字体**：窗口里的文字，包括面板、按钮和设置。
- **阅读字体**：船员在卡片上写的内容。
  在你选择别的字体之前，它保持为“**与应用字体相同**”。
- **代码字体**：代码、按键和任务编号。

每一种都可以选择 Infinitary 自己的字体、“**这台电脑的字体**”，或你的某个“**已安装的字体**”。

### 语言 {#language}

“**语言**”设置 Infinitary 显示的文字，以及你的大副和船员给你写信时使用的语言。
默认是英语。
其他语言有简体中文、繁体中文、日语、韩语、西班牙语、法语、德语、巴西使用的葡萄牙语和阿拉伯语，每种都用它自己的语言显示名称。
Infinitary 的部分地方仍显示英文。

### 声音 {#sound}

“**环境音乐**”播放在你电脑上生成的舒缓 lofi。
它跟随船员的动向，并在有事等你时发出提示音。
在你打开它之前它是关闭的，“**音量**”设置它播放的响度。

无论音乐是开是关，窗口顶部的“**设置**”前面都有一个声音按钮。
点击它即可打开或关闭音乐，“**环境音乐**”开关也会随之切换。
把指针停在它上面，会显示正在播放的音乐名称；把指针停在名称上，或点击名称，就能从下方的列表中选择其他风格。
命令搜索中也有“**播放或停止环境音乐**”和“**选择环境音乐**”。

## 操作手册 {#runbooks}

操作手册是大副和船员在某类工作中遵循的书面指南。

- “**内置**”列出随 Infinitary 提供的操作手册。
  “**查看**”可阅读其中一份，它的开关可打开或关闭它。
- “**你的**”列出你添加的，或与大副一起制作的操作手册。
- “**自己制作**”中有“**你的操作手册文件夹**”，它们存放在那里，旁边是“**打开文件夹**”。
  要制作一份，请用你自己的话问大副。

[你可以要求什么](/zh-hans/what-you-can-ask-for/)展示了一些内置操作手册所指引的工作，例如课程和供消遣的小项目。
请参阅[操作手册](/zh-hans/runbooks/)。
