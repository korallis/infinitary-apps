你的大副就是你在 Infinitary 中与之交谈的那一位。
它显示在窗口中央，负责带领你的船员。

## 大副做什么 {#what-your-first-mate-does}

- 它阅读你的消息，并判断需要什么：一个回答、一个反问，还是一项工作。
- 它能自己回答的问题，就在卡片上回答。
- 它把工作拆成任务，并为每个任务安排一名船员开始工作。
- 它跟踪每个任务，把你说的话转告船员，并在工作完成时将其结束。
- 当有事需要你决定时，它会给你送来一张卡片。

## 它交给船员做的事 {#what-it-leaves-to-the-crew}

你的大副不会编辑你的文件、阅读你的代码，也不会在你的项目中运行任何东西。
凡是需要你项目的文件、需要构建或需要查看哪里出了问题的事，都会交给船员。
每名船员都在你项目的独立工作副本中工作，因此你自己的文件保持原样。
请参阅[任务和船员](/zh-hans/tasks-and-crewmates/)。

## 与大副交谈 {#talking-to-your-first-mate}

在窗口底部的消息框中输入并发送。
你的消息和大副的简短回复会留在消息框上方。
点击回复即可阅读全文。

以下几点会有帮助：

- **从任何地方跳到消息框。**
  按 ⌘L（Linux 和 Windows 上按 Ctrl+L）。
- **找回你的上一条消息。**
  在空的消息框中按 ↑。
- **粘贴大量文字。**
  长篇粘贴会在消息框中变成一个文件标签，并随你的消息完整发送。

### 添加图片和文件 {#add-pictures-and-files}

把文件拖到消息框上，或点击“**添加文件**”。
图片和文本文件会随你的消息一起发送，每种最多四个。
对于其他类型的文件，例如 PDF，消息框会以文字形式添加该文件在你电脑上的位置，以便船员在那里打开它。

### 用说话代替打字 {#talk-instead-of-typing}

按一下或按住听写键即可说话。
消息框中的提示会说明是哪个键：“输入文字，或按一下/按住右侧 ⌥ 说话”。
在 Linux 和 Windows 上，这个键是右侧 Ctrl。
你说的话会在你的电脑上转成文字，发送前你可以编辑它。
要更改这个键或关闭听写，请使用[设置 → 通用](/zh-hans/settings/#general)中的“**听写**”。

### 在卡片上回答 {#answer-it-on-a-card}

当大副或船员送来一张卡片时，请直接在卡片上回答。
你在卡片下输入的内容会发给写这张卡片的人。
请参阅[卡片和决定](/zh-hans/cards-and-decisions/)。

## 选择它的模型 {#choosing-its-model}

你的大副通过你的某个订阅作答。
要选择使用哪个模型，请打开设置 → 智能，并使用“**大副模型**”。
“**自动（根据订阅）**”会让 Infinitary 从你的订阅提供的模型中挑选。
更改会在大副下次空闲时生效。

如果你在同一个服务商有两个账户，这一行会显示为“**大副模型和账户**”，你也可以选择账户。
你的船员的工作可以优先使用另一个账户：在该账户的菜单中使用“**优先用于船员工作**”。
请参阅[订阅和额度](/zh-hans/subscriptions-and-quota/)。

如果大副使用的订阅不再作答，例如因为你的套餐额度已用完，大副会显示一张卡片，说明原因以及你可以怎么做。
在此期间你发送的消息会被保留，等它能再次作答时就会送达。

## 让它的电脑保持开机 {#keep-its-computer-on}

你的大副住在一台电脑上。
你的手机和其他电脑都到那里找它。
请把它设置在一台尽量保持开机的电脑上。

当那台电脑处于睡眠状态，或那里的 Infinitary 已关闭时，大副就无法作答。
要在登录时打开 Infinitary，请在设置 → 通用中打开“**登录时启动**”。

要从别处联系大副，请参阅[你的其他电脑](/zh-hans/your-other-computers/)和 [iPhone 和 iPad](/zh-hans/iphone-and-ipad/)。
