title: 哪些内容会离开你的电脑
description: Infinitary 会发送什么、发送到哪里，以及唯一一个会向我们发送内容的开关。

Infinitary 在你的电脑上运行，使用的是你已有的订阅。
它不需要我们这边的账户，你的工作也不会经过我们。
本页列出应用会发送什么，以及发送到哪里。

## 你的工作会发送到你选择的服务商 {#your-work-goes-to-the-provider-you-chose}

你的大副和船员们通过你已登录的 AI 订阅来思考。
你的消息，以及船员为完成任务而读取的你项目中的内容，会通过你的订阅发送给该服务商。
使用 Claude 时，Infinitary 会使用你安装的 Claude Code，并登录你自己的账户。
使用自定义服务商时，内容会发送到你输入的地址。

你的登录信息会留在你的电脑上。

## 你的项目留在它们所在的地方 {#your-projects-go-where-they-live}

船员在你电脑上的项目工作副本中工作。
当任务以拉取请求的形式提交时，它的分支会被推送到你的项目托管处，例如 GitHub、GitLab 或 Bitbucket，拉取请求也在那里创建。
保存在这台电脑上的项目只会留在这台电脑上。

当船员准备工作副本或执行任务时，它可能会获取你的项目所需的内容，就像你手动操作那样。

## 你的其他电脑和手机 {#your-other-computers-and-your-phone}

你添加的电脑和手机会与大副所在的电脑通信。
设置 → “**设备**”会说明它们如何找到那台电脑。
“**通过互联网**”写着“从不。Infinitary 不会把这台电脑开放到互联网。”

你为另一台电脑输入的登录信息只会发送给那台电脑一次。
大副所在的电脑不保留任何副本。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。

## 你连接的集成 {#integrations-you-connect}

你在设置 → “**集成**”中连接的集成，例如 Google，会通过它自己的登录来访问，该登录会留在你登录时所用的电脑上。
只有在你连接之后，你的大副和船员们才会读取它。
请参阅[集成](/zh-hans/integrations/)。

## 你公司的用量报告 {#your-companys-usage-reporting}

如果你的 Claude Code 设置文件或 shell 按照 Claude Code 指南为你的公司设置了用量报告，Infinitary 会把在这里完成的所有工作的用量发送到同一个地方。
Claude 的工作以 Claude Code 自己会发送到那里的记录发送。
其他模型的工作以相同的名称发送，附带模型、提供方、token、估算费用、由大副还是船员完成、工作类型，以及你的 Claude Code 登录邮箱，从不包含你的文字、任务标题或项目名称。
设置 → “**用量**”会说明它发往何处。
如果那个地方一直拒收 Claude 的工作，或无法访问，这一行会改为说明这一点。
由你公司的管理员为整台电脑管理的设置，会像以前一样直接作用于 Claude Code，Infinitary 也会以同样的方式把其他模型的工作发送到那里。
无论哪种设置，只要通过 gRPC 发送用量，就只会收到 Claude 的工作，这时设置 → “**用量**”也会这样说明。

## 检查更新 {#update-checks}

Infinitary 每隔几个小时会从发布版本的地方检查是否有新版本。
这次检查不会发送你的任何内容，也不会发送任何 ID。
每天的第一次检查和每月的第一次检查还会说明它是第一次，这样 Infinitary Labs 就能统计有多少台电脑在使用 Infinitary。
无论“**诊断**”开关如何设置，这一点都会发生，而通过 Homebrew 安装的副本不会发送它。
只有在你选择更新时，它才会下载新版本。
你也可以自己点击“**检查更新**”。
请参阅[更新和移除 Infinitary](/zh-hans/update-and-remove/)。

## 听写 {#dictation}

听写在你的电脑上把你的声音转成文字。
你第一次使用它时，会先询问你，再一次性下载它的语音模型。

## 诊断，唯一向我们发送内容的开关 {#diagnostics-the-one-switch-that-sends-to-us}

设置 → “**通用**” → “**共享**”中有“**诊断**”开关。
它是唯一会向我们发送内容的开关；不经过它就会到达我们这里的，只有上文所说的检查更新时每天第一次和每月第一次的说明，“**共享**”中也有对它的描述。
除非你把它关闭，否则它是开启的，应用中的任何功能都不依赖它。

首次启动时，消息框下方的通知会说明它发送什么，并有“**关闭**”和“**好**”两个按钮。
在你回答之前，不会发送任何内容。

“诊断”发送匿名的使用事件：

- 应用打开，
- 你的大副完成或未能完成一轮工作，只带有失败的类型，
- 首次设置进行到了哪一步，
- 以及，来自你添加的 iPhone 或 iPad：应用打开、完成设置、发送了一条消息，以及回答了一张卡片。

每个事件都带有应用版本和一个随机的安装 ID。
这个 ID 与你或你的电脑的任何信息都无关，并且每次关闭再重新打开“诊断”时都会换成新的。
不会发送你写的任何文字、任何名称或任何路径：绝不会发送对话、代码或卡片。
你的手机自己不发送任何内容；你的电脑在同一个开关下发送它的事件。

要确切看到会发送什么，请打开“**共享**”下的“**会离开这台电脑的内容**”。
它会显示安装 ID、等待发送的内容、已发送的内容，以及“诊断”可能发送的每一种事件。
关闭“**诊断**”后，就不会再记录或发送任何内容。

## 机密 {#secrets}

你保存在设置 → “**机密**”中的值会留在你的电脑上。
每个值都直接进入机密：Infinitary 不会再次显示它，大副和船员们也都拿不到它。
请参阅[机密](/zh-hans/secrets/)。
