description: 添加你的其他电脑，这样你就能在其中任何一台上控制大副，让它们运行你的项目的工作，并保留一份可以接手的副本。

你的大副住在一台电脑上。
它的任务、卡片和对话都留在那里。
在你添加的任何一台电脑上，你都可以控制你的大副，而你添加的任何一台电脑也都可以运行项目的工作。

这一切都在设置 → **设备** 的 **你的设备** 下。
用 ⌘, 打开设置（Linux 和 Windows 上用 Ctrl+,）。

## 大副所在的电脑 {#the-computer-where-your-first-mate-lives}

选一台尽量一直开着的电脑。
你的其他电脑和你的手机需要它保持唤醒，并且 Infinitary 处于打开状态。

当它休眠或无法联系时：

- 另一台电脑会显示它最后看到的内容，并写着“暂不能更改”。
  你在那里输入的消息不会发出，你的话会留在消息框里，直到那台电脑恢复。
- 自动化只会在那里的 Infinitary 打开且电脑处于唤醒状态时运行。
  期间错过的一次运行，会在它恢复时补跑一次。

## 添加一台电脑 {#add-a-computer}

1. 在大副所在的电脑上，打开设置 → **设备**。
2. 点击 **+ 一台电脑**。
3. 输入另一台电脑的地址，然后点击 **添加**。

建议先用地址添加电脑：之后这台电脑会让另一台保持最新，并自己连到它，设置完成后无需再去那里。
输入你用 SSH 连接另一台电脑所用的地址，例如 `you@mini.local`。
那台电脑上必须开启“远程登录”；在 Linux 上则是它的 SSH 服务器。
同一网络中的电脑会列在 **在此网络上** 下，你可以直接选择。
你也可以让大副来添加电脑，它会推荐要用的地址。

在新的 Mac 或 x64 Linux 电脑上，Infinitary 首次启动时会显示要输入的地址：选择 **从你大副的电脑上设置**。
它先显示这台电脑的私有网络地址（例如 Tailscale 的地址），再显示它在本地网络上的地址，每个地址旁都有 **拷贝**。
大副所在的电脑添加它之后，只要那个窗口里还没有设置过任何东西，它就会自己打开你的大副。
如果窗口里你已经登录、添加了项目或与它的大副交谈过，它会保留自己的大副；旁边是你自己从“终端”启动的 Infinitary 的窗口也是如此。
如果添加时那台电脑上的 Infinitary 是关闭的，无论里面设置过什么，它下次启动时都会打开你的大副。
Windows PC 和 Arm Linux 电脑则改用 **粘贴它的链接** 加入。

在地址下方，**那里无法打开“远程登录”？** 提供另外两种方式。
每种方式添加的是同一种电脑。

**在那里的 Infinitary 中粘贴链接**，适用于你就在那台电脑前，或它是一台 Windows PC 的情况。
复制链接，然后在另一台电脑上首次打开 Infinitary。
在 **你的大副在另一台电脑上** 下，选择 **粘贴它的链接**，粘贴后点击 **继续**。
Infinitary 会问一次是否要从那里控制你的大副；点击 **从这里控制它**。

**在那里运行命令**，适用于你可以在那里的“终端”中输入，但“远程登录”已关闭的情况。
复制命令，然后在另一台电脑的“终端”中运行一次，使用应该运行其工作的那个用户。
它会从这台电脑获取 Infinitary，所以两台电脑需要在同一个网络中。

当你的大副在一台 Windows PC 上时，**+ 一台电脑** 只提供链接和命令两种方式。

链接或命令只能使用一次，有效期十分钟，在此之前你可以点击 **停止** 来作废它。
你也可以从另一台电脑发起加入：首次启动时，选择 **通过地址加入**，输入大副所在电脑的地址。

## 从另一台电脑控制大副 {#control-your-first-mate-from-another-computer}

电脑一旦加入，在那里打开 Infinitary 就会看到你的大副。
窗口顶部显示“控制大副：”和那台电脑的名称。
你的卡片、任务和对话仍留在大副所在的电脑上。

每台电脑各自保留自己的外观、键盘和面板设置。
设置的其他部分，则是在大副所在的电脑上读取和更改。

要停止控制，请在那台电脑上打开设置 → **设备**，点击 **离开**。
要让一台电脑与大副所在的电脑断开，请打开它的菜单（它那一行上的三个点），然后选择 **移除**。
只用来控制你的大副的电脑，需要一条新链接才能回来。

## 运行工作的电脑 {#a-computer-that-runs-work}

你添加的任何一台电脑都可以运行项目的工作，那里不需要打开任何窗口。
它登录的是自己的订阅，在那里运行的任务只使用这些订阅。
请在设置 → **智能** 中让它登录订阅，每台电脑的登录都列在它的名称下。
然后给它一个项目。

在设置 → **项目** 中，打开一个项目并设置 **运行于**：**自动**、**这台电脑**，或 **你的电脑** 中的某一台。
当那台电脑无法联系时，项目的任务会等待，绝不会改在这台电脑上运行。

一台电脑也可以以大副所在电脑上的另一个用户身份运行工作。
点击 **+ 以另一个用户身份运行** 来生成它的命令。

移除一台运行工作的电脑时，会先把它未合并的工作转回来。

## 把任务移到另一台电脑 {#move-a-task-to-another-computer}

已开始的任务可以移到另一台运行工作的电脑上。
打开它的记录，点击 **移到一台电脑**，然后选择它的去处。
它会保留自己的任务编号、分支、文件和记录。
等它的船员做完手头的事，任务才会移走；在此之前你可以点击 **取消移动**。

## 另一台电脑上的文件 {#files-on-another-computer}

船员可以把你另一台电脑上的文件复制到它的任务中阅读。
它只读取：不会往另一台电脑上写入任何东西。
每次复制都会在任务的动态中添加一行，写明文件和它来自的电脑。

## 搬动你的大副 {#move-your-first-mate}

在一台运行工作的电脑的菜单（它那一行上的三个点）中，**把你的大副搬到这里** 会把你的大副搬到那台电脑上。
搬动之前，会先有一份列表显示有哪些事情挡在前面。
[机密](/zh-hans/secrets/)会留在它离开的那台电脑上，你需要在新电脑上重新登录你的订阅。

## 在另一台电脑上保留副本 {#keep-a-copy-on-another-computer}

一台运行工作的电脑可以保留你的大副的记录的实时副本。
如果大副所在的电脑随后丢失，或长时间无法联系，这台电脑就可以[接手](#take-over)。

1. 在大副所在的电脑上，打开设置 → **设备**，选择另一台电脑。
2. 打开它的菜单（它那一行上的三个点），然后选择 **在这里保留副本**。

它会先完整复制一次，之后复制你的大副保存的每一处变化。
它那一行会显示副本的进度，例如 **副本已同步** 或 **副本正在追上 · 3 处变化**；在它无法联系期间，则显示某个时间的 **副本**。
你可以在多台电脑上保留副本。

副本包含你的大副的任务、卡片、对话、知识和自动化。
在接手之前，那台电脑不会打开它。
副本本身不包含你的任何项目、登录或机密：

- 接手时，每个项目都会从它所在的地方重新克隆。
  只保存在丢失的那台电脑上的项目，会在那里从空白开始。
- 它菜单中的 **接手准备** 会列出那台电脑还需要什么，例如它自己对你的大副使用的每个订阅的登录，以及对你的项目托管处的登录。
  每一项都有一个按钮，例如 **在那里登录 GitHub**，可以从这个窗口开始那次登录。
- 同一份列表中的 **在那里保留机密**，在你于那台电脑上亲自确认后，会把你的机密与副本一起保留。
  请参阅[机密](/zh-hans/secrets/#when-your-first-mate-moves)。

那份列表中的 **不再保留副本** 会结束保留，那台电脑在恢复联系后会删除它的副本。

在合并、推送或使用机密之前，你的大副会等待，直到每个可联系的副本都有了到目前为止的全部变化。
接手的电脑因此知道哪些已经做过，不会再做一遍。

## 接手 {#take-over}

当大副所在的电脑无法联系时，保留副本的电脑可以接手：你的大副会在那里从它的副本启动。
没有任何电脑会自行接手，也没有计时器来决定：只有你的点击才算数。

在一台保留副本的电脑上打开 Infinitary，并打开设置 → **设备**。
在 **正在控制** 下，**接手** 会写明这份副本来自什么时候，以及你的大副所在的电脑是说它要去休眠，还是说那里的 Infinitary 已退出。
它也会列出其他每份副本，当某份可能包含更多变化时，会标上 **可能更新**。
如果有更新的副本可以联系到，这台电脑会先把它取来。

1. 点击 **接手**。
2. 再次点击 **接手** 来确认，或点击 **留下** 让一切保持原样。
3. 在 Mac 上，用触控 ID 或你的密码确认；在 Windows 电脑上，用 Windows Hello 或你的 Windows 密码确认。

你的大副随后会在这台电脑上启动，这台电脑成为大副所在的电脑。
你的其他电脑和你的手机会自行在那里找到它，不需要新链接。
那里的一张卡片会询问它缺少的每个登录，除非它保留了机密，否则你需要重新添加你的机密。

你的手机也可以请求一台电脑接手。
当你的电脑无法联系时，点击手机顶栏右侧的电脑按钮。
它的面板会为每台保留副本的电脑提供 **接手**，然后要求验证 Face ID 或你的密码。

### 如果丢失的电脑回来了 {#if-the-lost-computer-comes-back}

丢失的那台电脑回来后，不再是你的大副所在的电脑，转而保留一份副本。
在 **已交接** 下，它的设置 → **设备** 会列出它在副本之后保存的内容，这些内容从未传到你的大副那里。
它会把那份记录另外存放，之后不会再打开。

如果两台电脑都以你的大副的身份应答，设置 → **设备** 会在 **两个大副** 下询问：**保留这个**，或保留另一个。
在你选择之前，合并、推送和机密使用都会等待；你不保留的那个会停下，并保留另一个的副本。

## 电脑如何互相找到 {#how-computers-find-each-other}

设置 → **设备** 显示 **其他设备如何找到这台电脑**：**在此网络上** 和 **在你的私有网络上**。
**通过互联网** 显示“从不。Infinitary 不会把这台电脑开放到互联网。”
要从别处控制你的大副，请把两台电脑放在同一个私有网络中。

另请参阅 [iPhone 和 iPad](/zh-hans/iphone-and-ipad/) 与[故障排查](/zh-hans/troubleshooting/)。
