卡片是你的大副或船員把東西交給你的方式。
一張卡片只裝一個答案、一項發現或一個決定，並附上背後的證據。
卡片會出現在視窗中央，蓋在大副上方。

## 卡片堆 {#the-stack}

有不只一張卡片在等你時，它們會疊成一堆，你一次看到一張。
新卡片送達時，不會把你正在讀的那張推開。

- **顯示下一張卡片**：⇧⌘]（Linux 和 Windows 上是 Ctrl+Shift+]）。
- **顯示上一張卡片**：⇧⌘[（Linux 和 Windows 上是 Ctrl+Shift+[）。

有卡片在等你的任務，會列在「任務」的「等你處理」底下。
這一頁列的是標準按鍵；[鍵盤](/zh-hant/keyboard/)會針對你能選的每一組按鍵配置，列出所有按鍵。

卡片分成兩種，標示在卡片頂端：

- **筆記** 告訴你一件事，不需要你回答。
  它只有一個按鈕 **知道了**，如果讀完就會結束它所回覆的任務，按鈕則是 **完成**。
- **決定** 請你做選擇。
  它提供兩到三個選項，作者建議的那個就是主要按鈕。

大多數決定也有一個不顯眼的 **拒絕** 按鈕，用來對所有選項說不。

## 回覆決定 {#answering-a-decision}

按下一個按鈕就是做出選擇。
⌘1（Linux 和 Windows 上是 Ctrl+1）會按下主要按鈕，⌘2 到 ⌘4 則按下其他按鈕。

有些卡片會在內文裡問不只一個問題，每個問題都放在它所針對的部分旁邊。
每個問題都選好答案，再按一個按鈕把它們一起送出。
在卡片裡點選，本身絕不會送出任何東西。

- 不會有選項替你預先選好。
  作者建議的選項會帶著 **建議** 標籤。
- 可以略過的問題，則會在那個選項上標示 **預設**。
  如果你沒有動那個問題，你的答案就是預設選項。
- 按鈕旁的數字會告訴你還有幾個問題需要回答。
- 每個有選項的問題最後都有 **其他**。
  選它之後，在打開的欄位裡寫下你自己的答案。

## 回覆欄與討論串 {#the-reply-field-and-the-thread}

大副或船員送來的每張卡片，內文底下都有一個寫著「還有要補充的嗎？」的欄位。

- 在裡面輸入文字再按 **聊天**，就能只回覆而不做選擇。
- 在裡面輸入文字再按一個選項，你的話就會和那個選項一起送出。

回覆會送給寫這張卡片的人。
第一則回覆會在卡片旁打開一個討論串，作者會在那裡回答。
作者為了回應而修改卡片時，卡片會就地更新，討論串也會註明。
要把討論串收回卡片裡，按 ⌘\（Linux 和 Windows 上是 Ctrl+\）。

作者處理你的回覆時，卡片會留在原位。
船員會在完成後重新繪製一次它的卡片。

## 把卡片放到一旁 {#putting-a-card-aside}

每張卡片的角落都有一個減號，**放到一旁**。
它會把卡片藏起來，但不回答。
你選的答案和輸入的文字都會跟著卡片保留。
卡片會在「任務」的「等你處理」底下等著，作者修改它時就會回來。

- **把卡片放到一旁**：⇧⌘M（Linux 和 Windows 上是 Ctrl+Shift+M）。
- **把所有卡片放到一旁或拿回來**：⌥⇧⌘M（Linux 和 Windows 上是 Ctrl+Alt+Shift+M）。

要把卡片拿回來，在「任務」裡點它的任務。

## 合併卡片 {#merge-cards}

變更準備好時，負責的船員會帶來一張合併卡片。
它會說明這個變更的來龍去脈：為什麼要改、改了什麼，以及檢查了什麼。

**變更前後的畫面。**
變更動到的每個畫面，都會並排顯示它之前和之後的樣子。
新的畫面只會顯示之後。
點一下畫面就能放大看。
示範錄製內容會有一個播放按鈕。

**風險圖。**
卡片右上角有一張小圖，用七個面向為這個變更評分：影響範圍、行為、復原、證據、敏感度、新穎度和相依套件。
每個面向分成低、中、高，形狀會朝較高的面向延伸。
把滑鼠停在圓點上，就能讀到船員的理由。
沒有總分。

**按鈕。**
**合併 pull request** 會合併它，**仔細審查** 會先要求一次獨立審查，**捨棄** 則會放棄這份工作。
檢查執行中或未通過時每個按鈕會做什麼，請參閱[你的第一項任務](/zh-hant/your-first-task/)。

## 只有你能做的事 {#things-only-you-can-do}

有時變更合併之後，需要做一件只有你能做的事，例如更新另一台電腦上的程式。
這時合併卡片會把它列在最上方的「合併之後，你需要…」底下，並說明如果你晚點再做會怎樣。

你合併之後，這些事項會各自變成一張卡片回來。
照著上面說的做，再按它的按鈕確認。
如果沒有成功，把你看到的內容貼進它的欄位，選擇 **沒有成功**，你的大副就會安排修正。
**暫時不要** 會把它留在「任務」的「等你處理」底下。

## 過去的卡片 {#past-cards}

你回答過的卡片都會保留。
打開它的任務並選擇 **卡片** 分頁，就能再讀一次，連同你當時的選擇。
