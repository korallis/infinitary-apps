這些是 Infinitary 賦予特定意思的詞語，依英文字母順序排列，每個詞旁邊附上它的英文名稱。
每一個都連結到完整解釋它的頁面。

## A {#a}

### 動態（Activity） {#activity}

視窗左側底部的面板，大副和船員做的每件事都佔一行。
任務自己的那幾行，在它卡片的 **動態** 分頁上。
請看 [面板](/zh-hant/panels/#the-apps-own-panels)。

### 額度（Allowance） {#allowance}

你的 AI 方案在重設之前還剩多少，例如每次對話或每週的額度。
設定 → **智慧等級** 會在每個帳號上以量表顯示它。
請看 [訂閱方案與額度](/zh-hant/subscriptions-and-quota/#read-your-plans-allowance)。

### 合併前先問過你（Ask before merging） {#ask-before-merging}

專案的一個開關，決定由誰來合併它完成的工作。
開啟時，工作會等你在它的合併卡片上點按；關閉時，通過檢查的工作可能不經詢問就合併。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/#asking-before-merging)。

### 自動化（Automation） {#automation}

大副依排程、或每當某件事發生時（例如一項任務結束）收到的一段提示。
請看 [自動化](/zh-hant/automation/)。

## B {#b}

### 待辦清單（Backlog） {#backlog}

任務在你按下它的 **開始** 之前等待的地方。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/#where-a-task-stands)。

### 批次（Batch） {#batch}

對於變更以 **批次 pull request** 提出的專案，指的是一個合併了你核准的變更的 pull request，每個變更各一個提交，並在檢查通過後合併。
正在等它的批次的變更，會在「任務」裡顯示「批次」。
請看 [專案](/zh-hant/projects/#how-changes-reach-your-project)。

### 分支（Branch） {#branch}

用 git 保存的專案裡，一條獨立的變更路線。
每位船員都在自己的分支上做變更，合併則會把它們帶進你的專案。
請看 [專案](/zh-hant/projects/#working-copies)。

## C {#c}

### 卡片（Card） {#card}

大副或船員帶給你一個答案、一項發現或一個決定的方式，並附上背後的證據。
卡片會一次一張出現在視窗中央，每一張都是 [筆記](#note) 或 [決定](#decision)。
請看 [卡片與決定](/zh-hant/cards-and-decisions/)。

### 檢查（Checks） {#checks}

你的專案在變更合併之前，對它執行的測試和其他檢查。
**檢查通過後合併** 會等它們，檢查未通過時船員會修正。
請看 [你的第一項任務](/zh-hant/your-first-task/#5-merge-it)。

### 指令搜尋（Command search） {#command-search}

一個能找到 Infinitary 裡任何指令並顯示它的按鍵的搜尋框。
在 Mac 上按 ⌘K，在 Linux 和 Windows 上按 Ctrl+K。
請看 [鍵盤](/zh-hant/keyboard/#command-search)。

### 執行工作的電腦（Computer that runs work） {#computer-that-runs-work}

你加入的另一台電腦，負責你專案的工作，不需要在那裡打開視窗，並使用它自己的訂閱方案。
設定 → **專案** 裡的 **執行於** 會為每個專案選擇電腦。
請看 [你的其他電腦](/zh-hant/your-other-computers/#a-computer-that-runs-work)。

### 大副所在的電腦（Computer where your first mate lives） {#computer-where-your-first-mate-lives}

保存你的大副、以及它的任務、卡片和對話的那一台電腦。
你的其他電腦和手機都在那裡找到大副，所以它需要保持喚醒，而且 Infinitary 是開著的。
請看 [你的其他電腦](/zh-hant/your-other-computers/#the-computer-where-your-first-mate-lives)。

### 正在控制（Controlling） {#controlling}

你加入的另一台電腦在開著 Infinitary 時做的事：從大副所在的電腦顯示你的大副。
它的視窗頂端會顯示「控制大副：」和那台電腦的名稱。
請看 [你的其他電腦](/zh-hant/your-other-computers/#control-your-first-mate-from-another-computer)。

### 大副的副本（Copy of your first mate） {#copy-of-your-first-mate}

由一台執行工作的電腦保留的大副紀錄即時副本，讓那台電腦可以 [接手](#take-over)。
請看 [你的其他電腦](/zh-hant/your-other-computers/#keep-a-copy-on-another-computer)。

### 船員的瀏覽器（Crew's browser） {#crews-browser}

船員為自己的任務使用的瀏覽器，和你自己的瀏覽器以及它的登入分開。
你可以觀看它、接手控制，而購買或預訂永遠由你來做。
請看 [船員的瀏覽器](/zh-hant/the-crews-browser/)。

### 船員（Crewmate） {#crewmate}

一位 AI 幫手，在它自己的專案工作副本裡處理一項任務的工作。
你所有的船員合起來就是你的船員團隊，由大副帶領。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/)。

## D {#d}

### 決定（Decision） {#decision}

一張要你做選擇的卡片。
它提供兩個或三個選擇，作者推薦的那一個是主要按鈕。
請看 [卡片與決定](/zh-hant/cards-and-decisions/#notes-and-decisions)。

### 診斷（Diagnostics） {#diagnostics}

唯一一個會傳東西給我們的開關：匿名的使用事件，不含你寫的任何文字、名稱或路徑。
它在設定 → **一般** 的 **分享** 底下。
請看 [哪些東西會離開你的電腦](/zh-hant/what-leaves-your-computer/#diagnostics-the-one-switch-that-sends-to-us)。

## F {#f}

### 大副（First mate） {#first-mate}

你在 Infinitary 裡說話的對象，畫在視窗中央。
它會回答你、把工作變成任務、為每項任務派一位船員開始，並帶卡片給你，而它自己絕不會編輯你的檔案。
請看 [大副](/zh-hant/the-first-mate/)。

### 聚焦（Focus） {#focus}

從頂端列的專案標籤，把視窗縮小到一個專案。
這時「任務」、「動態」和卡片只會顯示那個專案，你要求的新工作也會放到那裡，除非你指定另一個專案。
請看 [專案](/zh-hant/projects/#focus-on-one-project)。

## I {#i}

### 整合（Integration） {#integration}

以你的身分登入、連到專案以外某樣東西的連線，例如 GitHub、Gmail 或 MCP 伺服器。
你的大副、船員、自動化和面板都用同樣的方式使用它。
請看 [整合](/zh-hant/integrations/)。

## K {#k}

### 知識（Knowledge） {#knowledge}

大副和船員為之後的工作保留的東西：長期指引、個人背景和保存的來源。
請看 [知識](/zh-hant/knowledge/)。

## M {#m}

### 合併（Merge） {#merge}

把一項完成的變更帶進你的專案。
你從變更的合併卡片合併它；不需要合併前先問過你的專案，可能會不經詢問就合併它。
請看 [你的第一項任務](/zh-hant/your-first-task/#5-merge-it)。

### 合併卡片（Merge card） {#merge-card}

變更準備好時，船員帶來的卡片。
它說明這項變更的來龍去脈，附上之前和之後的圖片以及一張風險圖，它的按鈕則會合併或捨棄這份工作。
請看 [卡片與決定](/zh-hant/cards-and-decisions/#merge-cards)。

### 訊息框（Message box） {#message-box}

視窗底部的方塊，你在這裡打字給大副，或用說的代替打字。
在任何地方按 ⌘L（在 Linux 和 Windows 上是 Ctrl+L）就能移到它。
請看 [大副](/zh-hant/the-first-mate/#talking-to-your-first-mate)。

## N {#n}

### 筆記（Note） {#note}

一張告訴你某件事、什麼都不問的卡片。
它唯一的按鈕是 **知道了**，如果讀完就會結束它所回覆的任務，按鈕則是 **完成**。
請看 [卡片與決定](/zh-hant/cards-and-decisions/#notes-and-decisions)。

## O {#o}

### 連絡不上（Out of reach） {#out-of-reach}

用來形容 Infinitary 目前連不到的電腦或手機，例如正在睡眠、Infinitary 已關閉，或在另一個網路上。
需要它的工作會等到它回來。
請看 [疑難排解](/zh-hant/troubleshooting/#another-computer-is-out-of-reach)。

## P {#p}

### 面板（Panel） {#panel}

視窗側邊的一個方塊，例如「動態」、「任務」，或大副為你建置的面板。
請看 [面板](/zh-hant/panels/)。

### 個人背景（Personal context） {#personal-context}

你告訴大副的關於你自己的事，例如「我剛開始學寫程式」，保留下來讓之後的工作能用上。
請看 [知識](/zh-hant/knowledge/#tell-your-first-mate-about-yourself)。

### 計畫（Plan） {#plan}

船員在建置比較大的東西之前帶來的卡片，只問該由你做的決定。
**核准並建置** 會開始這份工作，**儲存並延後** 會把計畫留到之後。
請看 [你可以請它做什麼](/zh-hant/what-you-can-ask-for/#a-plan-before-building)。

### 私人網站（Private sites） {#private-sites}

你列出的、位於公司、家中或 VPN 網路上的網站，讓任務的瀏覽器可以打開它們。
大副絕不會自己新增網站：它會用卡片問你。
請看 [船員的瀏覽器](/zh-hant/the-crews-browser/#private-sites)。

### 專案（Project） {#project}

你自己的一個用 git 保存的資料夾，由你的船員在上面工作。
每項任務都屬於一個專案。
請看 [專案](/zh-hant/projects/)。

### Pull request {#pull-request}

在專案所在處（例如 GitHub 或 GitLab）提出、等待合併的變更，它的檢查會在那裡執行。
它合併卡片上的 **合併 pull request** 會合併它。
請看 [專案](/zh-hant/projects/#how-changes-reach-your-project)。

### 放到一旁（Put aside） {#put-aside}

不回答而把卡片藏起來。
它會在「任務」的 **等你處理** 底下等著，並在作者修改它時回來。
請看 [卡片與決定](/zh-hant/cards-and-decisions/#putting-a-card-aside)。

## Q {#q}

### 排入佇列（Queued） {#queued}

任務在它等的東西完成後（例如另一項任務）自己開始之前等待的地方。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/#where-a-task-stands)。

## R {#r}

### 紀錄（Record） {#record}

每項任務都會保留的東西：你要求了什麼、變更了什麼、證據，以及你的決定。
任務結束後，它的紀錄仍會保留。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/)。

### 謹慎度（Rigor） {#rigor}

工作在送到你面前之前被檢查得多徹底：**快速**、**預設** 或 **謹慎**。
每個專案在設定 → **專案** 裡都有自己的謹慎度。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/#rigor)。

### 作業手冊（Runbook） {#runbook}

大副和船員針對某種工作遵循的書面指引，例如規劃一項變更或教一堂課。
它不會在你的電腦上執行任何東西。
請看 [作業手冊](/zh-hant/runbooks/)。

## S {#s}

### 機密（Secret） {#secret}

船員依名稱使用的密碼或金鑰，只有在你允許那次使用之後才會使用。
Infinitary 不會再顯示它的值，大副和船員也都拿不到它。
請看 [機密](/zh-hant/secrets/)。

### 已登入的網站（Signed-in sites） {#signed-in-sites}

你在任務的瀏覽器裡登入過的網站，保存在那台電腦的瀏覽器設定檔裡。
你可以為每一個網站選擇，之後的任務要先問過你，還是不經詢問就使用。
請看 [船員的瀏覽器](/zh-hant/the-crews-browser/#signed-in-sites)。

### 長期指引（Standing direction） {#standing-direction}

用你自己的話說明從現在起你希望工作怎麼進行，由大副保留並遵循。
它適用於所有地方，或某一個專案。
請看 [知識](/zh-hant/knowledge/#give-a-standing-direction)。

### 訂閱方案（Subscription） {#subscription}

你已經有的 AI 方案，例如 Codex 或 Claude，大副和船員透過它工作。
你登入的每一個訂閱方案，都是設定 → **智慧等級** 裡的一個帳號。
請看 [訂閱方案與額度](/zh-hant/subscriptions-and-quota/)。

## T {#t}

### 接手（Take over） {#take-over}

在大副所在的電腦連絡不上時，於一台保留了大副副本的電腦上啟動大副。
只有你的點按才會讓它開始。
請看 [你的其他電腦](/zh-hant/your-other-computers/#take-over)。

### 任務（Task） {#task}

大副追蹤的一份工作，帶有像 `WEB-12` 這樣、以專案的任務編號前綴開頭的編號。
視窗右側的「任務」會依目前的狀態列出它們。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/)。

### 任務看板（Task board） {#task-board}

更完整的任務檢視：頂端是 **等你處理**，下面是待辦清單、排入佇列和工作中三欄。
按「任務」頁首的 **開啟任務看板**。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/#the-task-board)。

### 討論串（Thread） {#thread}

你第一次回覆時，在卡片旁開啟的對話。
卡片的作者會在那裡回答你。
請看 [卡片與決定](/zh-hant/cards-and-decisions/#the-reply-field-and-the-thread)。

## W {#w}

### 等你處理（Waiting on you） {#waiting-on-you}

「任務」列出帶有一張需要你做決定的卡片的任務的地方。
請看 [任務與船員](/zh-hant/tasks-and-crewmates/#where-a-task-stands)。

### 工作副本（Working copy） {#working-copy}

船員在它自己的分支上工作的一份專案副本，所以在你合併之前，你自己的檔案都會保持原樣。
請看 [專案](/zh-hant/projects/#working-copies)。
