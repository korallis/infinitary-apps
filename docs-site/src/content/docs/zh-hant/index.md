Infinitary 是你自己的 AI 工作室。
它是一款適用於 macOS、Linux 和 Windows 的桌面程式。
你只跟一位大副說話，由一群 AI 船員完成工作。

## 一項任務怎麼進行 {#how-a-task-goes}

1. 你在訊息框告訴大副你想要什麼。
2. 大副把你的要求拆成幾項任務，再把每項任務交給一位船員。
3. 每位船員都在你專案的專屬工作副本裡工作，所以你的檔案會留在原處。
4. 船員需要你做決定，或完成工作時，會帶一張卡片給你。
5. 你在卡片上做決定，船員就會繼續。

決定會以卡片的形式來到你面前。
船員只帶回你需要知道的事，決定權在你。

## 屬於你自己 {#your-own}

Infinitary 在你的電腦上執行，使用你已經有的 AI 訂閱方案。

- **你的電腦。**
  大副、船員和你的專案都在你的電腦上。
  工作在你自己專案的工作副本裡進行。
- **你的訂閱方案。**
  Infinitary 透過你已經有的訂閱方案運作。
  沒有點數，也不另外計量：供應商的帳單就是你的模型費用。
- **你的紀錄。**
  每項任務都會留下紀錄：你要求了什麼、改了什麼、有哪些證據，以及你做了什麼決定。
