Infinitary 裡的一切都能用鍵盤操作。
Tab 鍵在控制項之間移動，方向鍵在清單裡移動。

## 指令搜尋 {#command-search}

在 Mac 上按 <kbd>⌘K</kbd>，或在 Linux 和 Windows 上按 <kbd>Ctrl+K</kbd>，開啟指令搜尋。
輸入幾個字，用方向鍵選擇指令，然後按 Enter。
這一頁的每個指令都在那裡，旁邊附上它的按鍵，沒有按鍵的指令也在。

## 配置 {#presets}

Infinitary 內建幾組按鍵，稱為配置：Vim、Emacs、VS Code、Tmux、Legacy。
新安裝的 Infinitary 從 Vim 開始。
只有在配置出現之前就用過 Infinitary，才會看到 Legacy。
在 **設定** 的 **鍵盤** 下選擇配置。

## 更改按鍵 {#change-a-key}

在 **設定** 的 **鍵盤** 下，每個指令都有 **錄製**、**移除** 和 **重設**。
按 **錄製**，再按下你想要的按鍵，然後按 Enter 儲存。
如果另一個指令已經在用這些按鍵，Infinitary 會在任何變更之前告訴你是哪一個。
