面板是 Infinitary 視窗側邊的一個方塊。
面板排在兩條側欄上，一條在左、一條在右，圍繞著你和大副的對話。
沒有東西可顯示的側欄不佔空間。

每個面板都有一個帶標題的頁首。
點按頁首的箭頭，就能收合面板或再次展開。
收合的面板仍然可以用幾個字說明它裝了什麼，例如有幾項任務在等你。

## 程式本身的面板 {#the-apps-own-panels}

Infinitary 內建這些面板。

- **動態**，在左側欄的底部。
  它一行一行顯示大副和船員正在做什麼。
- **任務**，在右側欄的底部。
  它列出你的任務，並顯示哪些在等你。
  它的 **搜尋任務** 按鈕可以找到一項任務，**開啟任務看板** 則會打開整個看板。
- **知識**，在「任務」下面。
  它顯示大副保留的長期指引，**開啟知識** 則會打開船員學到的其餘內容。
  有知識可以顯示之後，它才會出現。
  請看 [知識](/zh-hant/knowledge/)。
- **自動化**，在「知識」下面。
  它列出你的自動化，以及每一項下次執行的時間。
  保存了一項自動化之後，它才會出現。
  請看 [自動化](/zh-hant/automation/)。

## 安排你的面板 {#arrange-your-panels}

你可以把任何面板移到任一條側欄的其他位置。

- **在側欄上。**
  按住面板的頁首並拖曳。
  一條線會顯示它將落在哪裡。
  在那裡放開就能移動它，在其他任何地方放開則會放回原處。
- **在設定裡。**
  打開 **設定**，再打開 **面板**。
  清單會依序顯示每條側欄的上方和下方群組。
  拖曳某一列就能移動它的面板，或用它的開關隱藏或顯示它。
  **重設為預設值** 會把每個面板放回最初的位置。
- **用說的。**
  告訴大副你想把面板放在哪裡，例如「把任務移到左側欄」。

你隱藏的面板會留在 **設定** 的清單裡，所以你可以再把它顯示出來。
當側欄空間不夠時，最靠近中間的面板會先收起來。
如果連它們的頁首都放不下，像 **還有 2 個** 這樣的一列會列出其餘的面板。
在那裡選一個，就能把它帶回側欄。

## 使用鍵盤 {#use-the-keyboard}

- 按 F6 移到視窗的下一個部分，面板也包括在內。
  Shift+F6 往回移。
- 按 ⌘,（在 Linux 和 Windows 上是 Ctrl+,）打開 **設定**。

有些面板會加入自己的指令，例如 **搜尋任務** 和 **開啟知識**。
你可以在指令搜尋裡找到它們，也可以在 **設定** 的 **鍵盤** 裡幫它們設定按鍵。
請看 [鍵盤](/zh-hant/keyboard/)。

## 大副為你建置的面板 {#panels-your-first-mate-builds-for-you}

你可以要求一個屬於你自己的面板。
告訴大副它應該顯示什麼，例如「幫我做一個顯示東京天氣的面板」。
船員會用程式本身的元件來建置它，所以它看起來和 Infinitary 的其他部分一致。

船員完成三項任務之後，左側欄頂端會出現一個空白的 **建立你自己的面板** 方塊。
點按它，就會在訊息框裡開始這個請求。
點按它的 **隱藏**，就會把它永久收起來。

你要求的面板會出現在左側欄的頂端，除非你說要放在哪裡。
它的頁首會顯示 **你的**。
你可以像移動其他面板一樣移動它。
想修改它，就告訴大副你想要哪裡不一樣。
想拿掉它，就請大副移除它。

## 關閉你的面板 {#turn-your-panels-off}

**設定** 的 **一般** 裡的 **你的面板**，會一次關閉大副為你建置的每個面板。
程式本身的面板會保留。
把開關重新打開，你的面板就會回來。

如果 Infinitary 在啟動後不久就連續關閉兩次，它會自動關閉你的面板，以防其中一個是原因。
這時開關會說明這件事。
準備好之後，再把它們重新打開。

如果你的某個面板停止運作，那個面板會說明，視窗的其他部分則照常運作。
當面板在背景中的工作停止回應時，它的 **重試** 按鈕會重新啟動它。
