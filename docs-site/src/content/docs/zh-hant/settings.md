用 ⌘,（在 Linux 和 Windows 上是 Ctrl+,）、視窗頂端的 **設定** 按鈕，或指令搜尋裡的 **開啟設定**，就能打開設定。
各個部分列在左側。
上下方向鍵可以在它們之間移動，按 Escape 或 **返回** 就會離開設定。

你也可以請大副幫你更改設定，例如「切換到淺色主題」或「開啟環境音樂」。

## 一般 {#general}

- **登入時啟動** 會在你登入電腦時打開 Infinitary。
- **在 Dock 中顯示**（在 Mac 上）關閉時會隱藏 Dock 圖示，視窗則會保留。
- **大副需要我時通知我** 會在視窗位於背景時，為決定和回報傳送安靜的通知。
- **聽寫** 讓你按一下或按住某個鍵來用說的代替打字，聲音會在你的電腦上轉成文字。
  關閉時，那個鍵和麥克風就留給其他 App 使用。
  請看 [大副](/zh-hant/the-first-mate/#talk-instead-of-typing)。
- **你的面板** 會撤下大副為你建置的每個面板，以及你加入的面板，直到你重新開啟它。
- **清除任務資料** 會移除每一項任務，連同它的工作副本、筆記和卡片，以及船員記錄下來的知識。
  按 **清除**，再按 **確認清除**。
- **分享** 裡有 **診斷** 開關、一行說明無論那個開關怎麼設定更新檢查都會告訴我們什麼，以及 **哪些東西會離開這台電腦**。
  請看 [哪些東西會離開你的電腦](/zh-hant/what-leaves-your-computer/#diagnostics-the-one-switch-that-sends-to-us)。
- **版本** 會寫出你執行的版本，並能再次打開你看過的每一份版本說明。
  在它底下，Infinitary 會說明你是否已經是最新版本，並附上像 **檢查更新** 這樣的按鈕。
  請看 [更新與移除 Infinitary](/zh-hant/update-and-remove/)。

在從別處控制大副的電腦上，「一般」還會列出 **網站登入**：你在那台電腦上的 [任務瀏覽器](/zh-hant/the-crews-browser/#signed-in-sites) 裡登入過的網站。
在大副所在的電腦上，它們在 **機密** 的 **已登入的網站** 底下。

## 外觀 {#appearance}

- **大小** 會讓文字和它周圍的一切變大，可選 100、110、125 或 150%。
- **預設卡片大小** 決定卡片打開時的大小：**一般**、**寬**、**全寬** 或 **最大化**。
  你仍然可以調整每張卡片的大小。
- **讓卡片保持最大化** 會在你將一張卡片最大化之後，讓每張卡片都保持最大化，直到你把其中一張還原。
- **主題** 有 **深色** 或 **淺色**。
- **視窗底色**（在 Mac 上）設定主題顏色覆蓋模糊背景的程度。
  預設是 0%。
- **船員模型名稱** 會在船員只使用一條軌道時顯示模型名稱。

### 字體 {#fonts}

Infinitary 有三種你可以選擇的字體：

- **應用程式字體**：視窗、面板、按鈕和設定裡的文字。
- **閱讀字體**：船員寫在卡片上的內容。
  在你選擇別的字體之前，它會保持 **與應用程式字體相同**。
- **程式碼字體**：程式碼、按鍵和任務編號。

每一種都可以選 Infinitary 自己的字體、**這台電腦的字體**，或你 **已安裝的字體** 之一。

### 語言 {#language}

**語言** 設定 Infinitary 顯示的文字，以及大副和船員寫給你時使用的語言。
預設是英文。
其他語言有簡體中文、繁體中文、日文、韓文、西班牙文、法文、德文、巴西葡萄牙文和阿拉伯文，每一種都用它自己的語言命名。
Infinitary 的某些部分仍然會顯示英文。

### 聲音 {#sound}

**環境音樂** 會播放在你電腦上產生的平靜 lofi 音樂。
它會跟著船員的狀態變化，並在有東西等你時發出提示音。
在你開啟之前它是關閉的，**音量** 可以設定它播放的音量。

無論音樂是開是關，視窗頂端 **設定** 的正前方都有一個聲音按鈕。
按下它就能開啟或關閉音樂，**環境音樂** 開關也會跟著切換。
把指標停在它上面，會顯示正在播放的音樂名稱；把指標停在名稱上，或按下名稱，就能從下方的清單選擇其他風格。
指令搜尋裡也有 **播放或停止環境音樂** 和 **選擇環境音樂**。

## 作業手冊 {#runbooks}

作業手冊是大副和船員針對某種工作遵循的書面指引。

- **內建** 會列出 Infinitary 附帶的作業手冊。
  **檢視** 可以閱讀其中一份，它的開關可以開啟或關閉它。
- **你的** 會列出你加入的，或你和大副一起製作的作業手冊。
- **自己製作** 有 **你的作業手冊資料夾**，也就是它們存放的地方，並附上 **開啟資料夾**。
  想製作一份，就用你自己的話請大副幫忙。

[你可以請它做什麼](/zh-hant/what-you-can-ask-for/) 列出了一些由內建作業手冊引導的工作，例如課程和好玩的小專案。
請看 [作業手冊](/zh-hant/runbooks/)。
