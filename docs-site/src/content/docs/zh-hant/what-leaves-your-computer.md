Infinitary 在你的電腦上執行，透過你已經有的訂閱方案運作。
它不需要我們的帳號，你的工作也不會經過我們。
這一頁列出程式會傳送什麼，以及傳到哪裡。

## 你的工作會送到你選擇的供應商 {#your-work-goes-to-the-provider-you-chose}

你的大副和船員透過你登入的 AI 訂閱方案來思考。
你的訊息，以及船員為了完成任務而讀取的專案內容，會透過你的訂閱方案送到那個供應商。
使用 Claude 時，Infinitary 會使用你安裝、並以你自己的帳號登入的 Claude Code。
使用自訂供應商時，內容會送到你輸入的位址。

你的登入資訊會留在你的電腦上。

## 你的專案會送到它所在的地方 {#your-projects-go-where-they-live}

船員在你電腦上的專案工作副本裡工作。
當一項任務以 pull request 提出時，它的分支會推送到專案所在處，例如 GitHub、GitLab 或 Bitbucket，pull request 也會在那裡開啟。
只放在這台電腦上的專案，就只會留在這台電腦上。

船員準備工作副本或執行任務時，可能會擷取專案需要的東西，就像你手動做的那樣。

## 你的其他電腦和手機 {#your-other-computers-and-your-phone}

你加入的電腦和手機，會和大副所在的電腦溝通。
設定 → **裝置** 會說明它們怎麼找到它。
**透過網際網路** 顯示的是「永遠不會。Infinitary 不會把這台電腦開放到網際網路上。」

你為另一台電腦輸入的登入資訊，只會傳到那台電腦一次。
大副所在的電腦不會留下副本。
請看 [你的其他電腦](/zh-hant/your-other-computers/)。

## 你連接的整合 {#integrations-you-connect}

你在設定 → **整合** 連接的整合（例如 Google），會用它自己的登入資訊連線，而這份登入資訊留在你登入的那台電腦上。
只有在你連接之後，大副和船員才會讀取它。
請看 [整合](/zh-hant/integrations/)。

## 你公司的用量回報 {#your-companys-usage-reporting}

如果你的 Claude Code 設定檔或 shell 依照 Claude Code 指南為你的公司設定了用量回報，Infinitary 會把在這裡完成的所有工作的用量傳送到同一個地方。
Claude 的工作以 Claude Code 自己會傳送到那裡的記錄傳送。
其他模型的工作以相同的名稱傳送，附帶模型、供應商、token、估算費用、由大副還是船員完成、工作類型，以及你的 Claude Code 登入電子郵件，從不包含你的文字、任務標題或專案名稱。
設定 → **用量** 會說明它送往何處。
如果那個地方一直拒收 Claude 的工作，或連不上，這一行會改為說明這一點。
由你公司的管理員為整台電腦管理的設定，會像以前一樣直接作用於 Claude Code，Infinitary 也會以同樣的方式把其他模型的工作傳送到那裡。
無論哪一種設定，只要透過 gRPC 傳送用量，就只會收到 Claude 的工作，這時設定 → **用量** 也會這樣說明。

## 更新檢查 {#update-checks}

Infinitary 每隔幾小時，會從發布版本的地方檢查有沒有更新的版本。
這項檢查不會傳送任何你的內容，也不會傳送任何識別碼。
每天的第一次檢查，以及每個月的第一次檢查，還會說明它是第一次，讓 Infinitary Labs 能計算有多少台電腦在使用 Infinitary。
無論 **診斷** 開關怎麼設定都會這樣做，而用 Homebrew 安裝的 Infinitary 不會傳送這項資訊。
只有在你選擇更新時，它才會下載新版本。
你也可以自己按 **檢查更新**。
請看 [更新與移除 Infinitary](/zh-hant/update-and-remove/)。

## 聽寫 {#dictation}

聽寫會在你的電腦上把你的聲音轉成文字。
第一次使用時，它會先問過你，再一次性下載它的語音模型。

## 診斷，唯一一個會傳東西給我們的開關 {#diagnostics-the-one-switch-that-sends-to-us}

設定 → **一般** → **分享** 裡有 **診斷** 開關。
它是唯一一個會傳東西給我們的開關；沒有它也會傳到我們這裡的，只有上面提到的更新檢查每天第一次和每月第一次的說明，**分享** 裡也有描述。
除非你關閉它，否則它是開啟的，而程式裡沒有任何功能依賴它。

第一次啟動時，訊息框下方的通知會說明它傳送什麼，並附上 **關閉** 和 **好**。
在你回答之前，什麼都不會傳送。

診斷會傳送匿名的使用事件：

- 程式開啟，
- 大副完成或未能完成一輪對話，只附上失敗的種類，
- 第一次設定進行到哪裡，
- 以及從你加入的 iPhone 或 iPad：程式開啟、完成設定、傳送訊息和回答卡片。

每個事件都會附上程式版本和一個隨機的安裝識別碼。
這個識別碼和你或你的電腦沒有任何關聯，而且每次關閉再重新開啟診斷時都會換新。
不會傳送任何你寫的文字、名稱或路徑：絕不會傳送對話、程式碼或卡片。
你的手機自己不會傳送任何東西；你的電腦會在同一個開關下傳送它的事件。

想確切知道會傳送什麼，請打開 **分享** 底下的 **哪些東西會離開這台電腦**。
它會顯示安裝識別碼、等待傳送的內容、已經傳送的內容，以及診斷可能傳送的每一種事件。
關閉 **診斷** 後，就不會再記錄或傳送任何東西。

## 機密 {#secrets}

你在設定 → **機密** 裡保存的值會留在你的電腦上。
每個值都會直接放進「機密」：Infinitary 不會再顯示它，大副和船員也都拿不到它。
請看 [機密](/zh-hant/secrets/)。
