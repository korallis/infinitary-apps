title: 你的其他電腦

你的大副住在一台電腦上。
它的任務、卡片和對話都留在那裡。
從你加入的任何一台電腦都能控制大副，你加入的任何一台電腦也都能執行專案的工作。

這些都在設定 → **裝置** 的 **你的裝置** 底下。
用 ⌘,（在 Linux 和 Windows 上是 Ctrl+,）打開設定。

## 大副所在的電腦 {#the-computer-where-your-first-mate-lives}

選一台盡量保持開機的電腦。
你的其他電腦和手機需要它保持喚醒，而且 Infinitary 是開著的。

當它睡眠或連絡不上時：

- 另一台電腦會顯示它最後看到的內容，並顯示「暫時無法變更」。
  你在那裡輸入的訊息不會傳送，你的話會留在訊息框裡，直到那台電腦回來。
- 只有在那裡的 Infinitary 開著、而且電腦保持喚醒時，自動化才會執行。
  期間錯過的執行，會在它回來時執行一次。

## 加入電腦 {#add-a-computer}

1. 在大副所在的電腦上，打開設定 → **裝置**。
2. 按 **+ 一台電腦**。
3. 輸入另一台電腦的位址，然後按 **加入**。

建議先用位址加入電腦：之後這台電腦會讓另一台保持最新，並自己連到它，設定完成後不必再去那裡。
輸入你平常以 SSH 連到另一台電腦時用的位址，例如 `you@mini.local`。
那台電腦必須開啟「遠端登入」；在 Linux 上則是它的 SSH 伺服器。
同一個網路上的電腦會列在 **在這個網路上** 底下，讓你可以直接選一台。
你也可以請大副加入電腦，它會推薦要用的位址。

在新的 Mac 或 x64 Linux 電腦上，Infinitary 第一次啟動時會顯示要輸入的位址：選擇 **從你大副的電腦上設定**。
它會先顯示這台電腦的私人網路位址（例如 Tailscale 的位址），再顯示它在區域網路上的位址，每個位址旁都有 **拷貝**。
大副所在的電腦加入它之後，只要那個視窗裡還沒設定過任何東西，它就會自己打開你的大副。
如果視窗裡你已經登入、加入了專案或和它的大副對話過，它會保有自己的大副；旁邊是你自己從「終端機」啟動的 Infinitary 的視窗也一樣。
如果加入時那台電腦上的 Infinitary 是關閉的，無論裡面設定過什麼，它下次啟動時都會打開你的大副。
Windows PC 和 Arm Linux 電腦則改用 **貼上它的連結** 加入。

在位址下方，**那裡無法開啟「遠端登入」？** 提供另外兩種方式。
每種方式加入的都是同一種電腦。

**在那裡的 Infinitary 中貼上連結**，適合你就在那台電腦前，或它是一台 Windows PC 的時候。
複製連結，然後在另一台電腦上第一次打開 Infinitary。
在 **你的大副在另一台電腦上** 底下，選擇 **貼上它的連結**，貼上後按 **繼續**。
Infinitary 會問一次是否要從那裡控制大副；按 **從這裡控制它**。

**在那裡執行指令**，適合你可以在那裡的「終端機」輸入，但「遠端登入」是關閉的時候。
複製指令，在另一台電腦的「終端機」裡，以應該執行它工作的使用者身分執行一次。
它會從這台電腦取得 Infinitary，所以兩台電腦需要在同一個網路上。

當你的大副在一台 Windows PC 上時，**+ 一台電腦** 只提供連結和指令兩種方式。

連結或指令只能用一次，效期十分鐘，在那之前你也可以按 **停止**。
你也可以從另一台電腦加入：在它第一次啟動時，選擇 **用位址加入**，再輸入大副所在電腦的位址。

## 從另一台電腦控制大副 {#control-your-first-mate-from-another-computer}

一台電腦加入之後，在那裡打開 Infinitary 就會顯示你的大副。
視窗頂端會顯示「控制大副：」和那台電腦的名稱。
你的卡片、任務和對話都留在大副所在的電腦上。

每台電腦都保有自己的外觀、鍵盤和面板設定。
設定的其他部分，則是在大副所在的電腦上讀取和更改。

想停止，就在那台電腦上打開設定 → **裝置**，按 **退出**。
想讓一台電腦和大副所在的電腦切斷連結，打開它的選單（在它那一列的三個點裡），選擇 **移除**。
只用來控制大副的電腦，需要新的連結才能回來。

## 執行工作的電腦 {#a-computer-that-runs-work}

你加入的任何一台電腦都能執行專案的工作，不需要在那裡打開視窗。
它會登入自己的訂閱方案，在那裡執行的任務只會使用這些訂閱方案。
在設定 → **智慧等級** 裡幫它登入訂閱方案，每台電腦的登入都列在它的名稱底下。
然後交給它一個專案。

在設定 → **專案** 裡打開一個專案，設定 **執行於**：**自動**、**這台電腦**，或 **你的電腦** 之一。
當那台電腦連絡不上時，這個專案的任務會等著，絕不會改在這台電腦上執行。

一台電腦也可以在大副所在的電腦上，以另一位使用者的身分執行工作。
按 **+ 以另一位使用者身分執行** 來產生它的指令。

移除一台執行工作的電腦時，會先把它尚未合併的工作帶回來。

## 把任務移到另一台電腦 {#move-a-task-to-another-computer}

已經開始的任務，可以移到另一台執行工作的電腦。
打開它的紀錄，按 **移到另一台電腦**，然後選擇要移到哪裡。
它會保留它的編號、分支、檔案和紀錄。
任務會在它的船員做完手上的事之後移動；在那之前，你可以按 **取消移動**。

## 另一台電腦上的檔案 {#files-on-another-computer}

船員可以把你另一台電腦上的檔案複製到它的任務裡來讀取。
它只會讀取：不會在另一台電腦上寫入任何東西。
每次複製都會在任務的「動態」裡加上一行，寫出檔案和它來自哪台電腦。

## 把大副搬家 {#move-your-first-mate}

在一台執行工作的電腦的選單裡（在它那一列的三個點裡），**把你的大副搬到這裡** 會把大副搬過去。
清單會先顯示任何擋在路上的事情。
[機密](/zh-hant/secrets/) 會留在它離開的那台電腦上，你也要在那裡重新登入你的訂閱方案。

## 在另一台電腦上保留副本 {#keep-a-copy-on-another-computer}

執行工作的電腦，可以保留一份大副紀錄的即時副本。
如果大副所在的電腦後來遺失了，或長時間連絡不上，那台電腦就能 [接手](#take-over)。

1. 在大副所在的電腦上，打開設定 → **裝置**，選擇另一台電腦。
2. 打開它的選單（在它那一列的三個點裡），選擇 **在這裡保留副本**。

它會先取得一份完整的副本，之後再取得大副保存的每一項變更。
它那一列會說明副本目前的狀態，例如 **副本已同步** 或 **副本正在追上 · 3 項變更**，連絡不上時則顯示某個時間 **的副本**。
你可以在不只一台電腦上保留副本。

副本包含大副的任務、卡片、對話、知識和自動化。
在接手之前，那台電腦絕不會打開它。
副本本身不包含你的任何專案、登入或機密：

- 接手時，每個專案都會從它所在的地方重新複製。
  只放在遺失的那台電腦上的專案，會在那裡從空的開始。
- 它選單裡的 **接手準備** 會列出那台電腦還需要什麼，例如它自己對大副使用的每個訂閱方案的登入，以及對專案所在處的登入。
  每一項都有一個按鈕，例如 **在那裡登入 GitHub**，能從這個視窗開始那項登入。
- 同一份清單裡的 **在那裡保留機密**，會在你於那台電腦本身上確認後，把你的機密和副本一起保留。
  請看 [機密](/zh-hant/secrets/#when-your-first-mate-moves)。

那份清單裡的 **不再保留副本** 會結束它，那台電腦在連絡得上時就會刪除它的副本。

在合併、推送或使用機密之前，大副會等到每份連絡得上的副本都有目前為止的每一項變更。
這樣一來，接手的電腦就會知道哪些事已經做過，不會再做一次。

## 接手 {#take-over}

當大副所在的電腦連絡不上時，保留副本的電腦可以接手：大副會從它的副本在那裡啟動。
沒有任何東西會自己接手，也沒有計時器會做決定：只有你的點按會。

在保留副本的電腦上打開 Infinitary，再打開設定 → **裝置**。
在 **正在控制** 底下，**接手** 會說明這份副本是什麼時候的，以及大副的電腦是否曾表示它要進入睡眠，或那裡的 Infinitary 已經結束。
它也會列出每一份其他的副本，可能包含更多變更的會標為 **可能較新**。
如果有較新的副本連絡得上，這台電腦會先把它帶進來。

1. 按 **接手**。
2. 再按一次 **接手** 確認，或按 **留下** 維持現狀。
3. 在 Mac 上，用 Touch ID 或你的密碼確認；在 Windows 電腦上，用 Windows Hello 或你的 Windows 密碼確認。

接著大副會在這台電腦上啟動，這台電腦就成為大副所在的電腦。
你的其他電腦和手機會自己在那裡找到它，不需要新的連結。
那裡會有一張卡片要求它缺少的每一項登入，除非它保留了你的機密，否則你要再加入一次。

你的手機也可以要求一台電腦接手。
當你的電腦連絡不上時，點一下手機頂端列右側的電腦按鈕。
它的面板會為每一台保留副本的電腦提供 **接手**，然後要求 Face ID 或你的密碼。

### 如果遺失的電腦回來了 {#if-the-lost-computer-comes-back}

遺失的電腦回來時，就不再是大副的電腦，而是改為保留一份副本。
在它的設定 → **裝置** 的 **已交接** 底下，會列出它在副本之後保存、從未傳到大副那裡的內容。
它會把那份紀錄另外放著，不會再打開它。

如果兩台電腦都以大副的身分回應，設定 → **裝置** 會在 **兩個大副** 底下詢問：**保留這個**，或保留另一個。
在你選擇之前，合併、推送和使用機密都會等著，你沒有保留的那一個會停止，並保留另一個的副本。

## 電腦如何找到彼此 {#how-computers-find-each-other}

設定 → **裝置** 會顯示 **其他裝置如何找到這台電腦**：**在這個網路上** 和 **在你的私人網路上**。
**透過網際網路** 顯示的是「永遠不會。Infinitary 不會把這台電腦開放到網際網路上。」
想從其他地方控制大副，請讓兩台電腦連上同一個私人網路。

另請參閱 [iPhone 和 iPad](/zh-hant/iphone-and-ipad/) 和 [疑難排解](/zh-hant/troubleshooting/)。
