A home's account list may hold more than one Claude account: each one after the first is a login in its own Claude Code folder on the home's own computer.
No request, push or order changes shape, and a computer that runs work still holds one Claude login.
An older side shows and uses every such account as it does any other account row, and refuses a second Claude account as before.
An older build of the home's own app refuses the saved-data folder while it holds such an account (`docs/saved-data-compatibility.md`, "Further Claude logins").
