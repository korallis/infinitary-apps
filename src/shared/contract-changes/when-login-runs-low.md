Adds the requests `inf:settings:when-login-low:get` and `inf:settings:when-login-low:set`, which read and save what Infinitary does when the login in use of a provider runs low: `wait`, `ask`, `spread` or `move`.
Adds the host operation `move-login` to the card a low login raises and to the first mate's pause card: its click moves the provider's login in use, or the first mate, to the named login of the same provider.
A desktop view without the change is never sent a Move to another login button, since it reads a card's buttons strictly, and never asks for the choice.
